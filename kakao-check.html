카카오 로그인 설정 확인

카카오 디벨로퍼스와 Supabase 설정이 맞는지 운영진이 직접 로그인해 확인하는 화면입니다. 사이트의 글, 참석, 운영 자료는 바꾸지 않습니다.

확인 순서

  1. 아래 '카카오 로그인'을 누릅니다.
  2. 카카오 동의 화면에 닉네임만 보이는지 봅니다.
  3. 이 화면으로 돌아와 '설정이 맞습니다'가 나오면 끝입니다.
  4. 확인이 끝나면 '로그아웃'을 누릅니다.

확인 중입니다.

막히면

  • 카카오 화면에 KOE006: 카카오의 리다이렉트 URI가 https://drggzlnzwvkhtalvkqyo.supabase.co/auth/v1/callback 와 글자 하나까지 같은지 봅니다.
  • 카카오 화면에 KOE205: 요청한 동의항목이 카카오 설정에 없습니다. 화면에 적힌 항목 이름을 개발 세션에 알려 주세요.
  • 로그인 뒤 이 화면이 아니라 홈으로 가면: Supabase의 Redirect URLs에 https://excer-site.vercel.app/** 가 없습니다.
  • 이 확인으로 Supabase에 운영진 본인의 로그인 정보가 하나 생깁니다. 필요 없으면 Supabase의 Authentication > Users에서 지울 수 있습니다.
