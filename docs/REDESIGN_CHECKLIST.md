## 2. 콘텐츠 종류별 정리 양식 (요약 — 전문은 CONTENT_FORMAT.md)

- 맛집: 식당명 · 지역(+위치 메모) · 종류 · 1인 가격 · 추천 메뉴 · 한줄평 · 방문 팁 · 작성자 · 등록일/방문일 · 지도. 목록은 1~6 순서, 상세는 기본 정보→추천 메뉴→방문 후기→방문 팁→위치와 지도→작성 정보.
- 소식: 공지(핵심 안내·적용 대상·적용일/종료일·필요한 행동·상세) / 모임 모집(모임명·날짜·시간·장소·인원·비용·모임장·신청 방법·준비물·상태) / 모임 후기(활동·날짜·장소·본문·링크) / 정보(핵심 내용·출처·링크·유효 기간) / 자유(제목·본문). 저장은 `site_posts.meta`, 서버 정리기가 아는 키만 남김.

## 4. 새 등록·수정 흐름

- 맛집 등록/수정: 식당 이름 → 지역·종류 → 주소 또는 위치 → 지도 링크 → 1인 가격·메모 → (등록 시) 첫 한줄평(선택: 한줄평·추천 메뉴·방문 팁·방문일·1인 금액·재방문) / (수정 시) 영업 종료 → 작성 정보 → 목록 미리보기(첫 한줄평도 목록 규칙 그대로). 저장은 place_create → (한줄평이 있으면) place_note_create 한 번. 한줄평 없이 메뉴·팁만 적으면 한줄평을 요구(가짜 후기 문장 없음). 오류는 항목 아래, 서버 오류(같은 식당·비밀번호·링크·방문일)도 해당 항목에.
- 한줄평 등록/수정: 한줄평(필수) → 추천 메뉴 → 방문 팁 → 방문일 → 1인 금액 → 다시 가고 싶음 → 작성 정보 → 상세 미리보기. 수정은 정리본을 미리 채움. 서버가 이전 형식이면 메뉴·팁 칸을 닫고 안내.
- 소식 글쓰기/수정: 글 종류 → (유형별 항목) → 제목(모집은 모임명) → 내용 → 작성 정보 → 목록 행 + 항목 표 미리보기. 수정도 같은 모달, 항목이 채워짐.
- 우선순위: 작성자가 수정한 서버 값 > 정리본(원문이 같을 때만) > 원문.

## 16. 실기기 레이아웃 재검토 — 주요 기능 카드 잘림과 iOS 보정 (2026-09-22, 11차)

운영자가 폰(카톡 안 브라우저)에서 홈 '주요 기능' 카드의 그림이 잘리거나 칸을 넘는 것을 보고, 전체 레이아웃의 부정확·어색·잘못된 배치를 검토해 달라고 했다. 크로미움 헤드리스에서는 멀쩡했던 것이라 실기기(iOS 사파리·WKWebView) 차이를 중심으로 봤다. 8개 관점(iOS 호환·폰 폭·태블릿 폭·PC 폭·시각 일관성·그림 자리·입력 양식과 모달·데이터 상태별)의 병렬 감사를 돌려 80여 건을 모았고, 크레딧 사정으로 검증 단계 초반에 멈춘 뒤 근거가 분명하고 고치기 싼 것부터 반영했다.

- **원인(주요 기능 카드)**: `.tc-img` 가 `aspect-ratio` 상자 + 자식 `img { height: 100% }` 구조였는데, iOS 사파리는 그 상자의 높이를 percentage 기준으로 잡지 못해 그림이 자연 높이(정사각)로 커지고 상자에 잘렸다. padding 으로 비율을 잡고(`::before { padding-top: 62.5% }`) 그림을 절대 위치로 채우는 구조로 바꿈(contain 유지). 못 읽으면 크림 상자 대신 글만.
- **iOS 폴백**: `dvh` 앞에 `vh`(본문 최소 높이·모달·바닥 시트), 히트맵 칸 padding 정사각, 소식 알림 위치를 `:has()` 없이도 떠 있는 버튼 위로.
- **iOS 초점 확대(검증 확정)**: 손가락 화면에서 폼 컨트롤 글자 16px 미만이면 iOS 가 초점 때 화면을 확대하고 되돌리지 않는다 — 안내 검색 15px, 소식 정렬 14px, 맛집 필터 15px, 통계 select, 정산 추가·차감 14px. `@media (hover: none) and (pointer: coarse)` 에서 input·select·textarea 를 16px 로 고정.
- **iOS select·date 모양(검증 확정)**: `select.input` 과 date·time 입력이 iOS 기본 menulist 모양이라 옆 칸(44px·8px 모서리)과 높이가 달랐다 → appearance 를 끄고 우리 테두리 + SVG 화살표. (검색 칸의 알약 모양 주장은 검증에서 기각 — iOS 15~17 은 작성자 테두리를 유지.)
- **긴 닉네임 넘침**: `html { overflow-wrap: anywhere }`(넘칠 때만 끊음) + 정산 영수증 입금 명단의 이름을 말줄임(바깥 span 이 줄어들도록) — 한 사람 이름 때문에 전원의 금액·복사 버튼이 카드 밖으로 밀리던 것. 요약 타일 금액은 100만 원(7자리)도 들어가게 글자 크기 clamp.
- **폰에서 잘려 안 보이던 것**: 소식 종류 탭(자유)은 480px 이하에서 두 줄로, 맛집 종류 칩 3개(술집·카페·분식)는 줄바꿈으로(스크롤 단서가 없었다). 히트맵 '한 화면' 규칙을 480 → 640px 까지.
