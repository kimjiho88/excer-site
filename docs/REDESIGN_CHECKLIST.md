# 전체 정비 점검표 (내부용, 배포 제외)

기준: 성인 사용자를 위한 차분한 동네 커뮤니티. 제목만으로 목적 이해, 기능 우선, 간결한 한국어, 일관된 정렬·간격·조작, 실제 데이터 밀도, 오류·빈 상태까지 완성.

용어: 멤버 / 모임(벙) / 모임장(벙주) / 모임 비용·정산 금액 / 오픈채팅 / 글쓰기 / 지도에서 보기

## 2차 감사 반영 (워크플로 감사 137건 → 확인 75건 반영, 기각 13건, 미검증 49건은 직접 확인)

- 홈: 맛집 빈 상태·실패 상태 전체 폭, 다시 시도 누르면 '불러오는 중' 표시, 카드 링크 → 맛집 페이지 해당 식당으로 이동
- 이용 안내: 검색 중 이동 링크가 숨은 섹션도 열어 줌, 접힌 아코디언은 탭 순서에서 제외, 목차·이동 링크 후 제목으로 포커스, PC 목차 접힘 방지, 중복 건너뛰기 링크 제거
- 활동 통계: 발행 기간 표기, 기본 기간은 잘리지 않는 가장 좁은 기간(기준 주→기준 월→전체), '메시지 증감순', 순위 검색은 걸러 내고 결과 없음 표시, y축 정수 눈금, 히트맵 빈 상태에서 요소 유지, 연결 실패는 예시 데이터로 덮지 않음(다시 시도), 단어 분류 숫자 제거, '벙'은 화면에서 '모임'
- 모임 정산: 입금 현황 새로고침 실패 상태, 라이브 영역 하나로, 이모지 대신 왼쪽 선, 보조 설명 규칙, 추가·차감 설명을 계산과 일치, 죽은 CSS 제거, 숫자 tabular, 멤버·옵션 선택 aria-pressed, '@이름' 줄바꿈 방지
- 정산 확인: '토스로 송금', 값 없을 때 '—', 본문 aria-live 제거 + 작은 상태 영역, 다시 그린 뒤 포커스 복원, 해제 안내, 계좌 없는 링크 안내, aria-current="true"
- 소식: 수정 폼 카테고리 표시, 늦은 응답 무시(reqSeq), 실패 안내 하나, 날짜 표기 통일, 리액션 바 여백, 스켈레톤 정리, 지난 모임 표시 중복 제거, 카테고리 aria-pressed, 본문 16px, 글쓰기 버튼 하나, 포커스 복원
- 맛집: '방문 많은 순', 수정 모달 버튼 '수정/저장 중', '그 외 지역' 세 곳 통일, 최근 방문순 정렬 분리, 날짜 표기, 목록 aria-live 제거, 펼침 영역 id·조건부 aria-controls·포커스 복원, 테마 색, '삭제' 통일, 한줄평 삭제는 비밀번호 창, #place-N 진입
- 게임: 저장 방식 설명을 실제 구현(구글 로그인 / 익명 서버 보관)에 맞춤, 빵집 순위 행, 한 문장 소개, 복귀 링크 '‹ 게임'
- 공통: 파비콘 통일, .reveal/data-countup 죽은 코드 제거, 아코디언 접힘 visibility, 홈 제목 40/30px, 폼 컨트롤 공통 규칙(.field/.input/.textarea/.field-hint), 푸터 저작권 글자 크기, 모바일 숫자 줄 정렬

## 3차 반영 (모임 정산 후속)

- 추가·차감: 한 버튼을 눌러 바꾸던 부호를 `＋ 추가 | − 차감` 두 칸이 항상 보이는 선택으로. 금액에 `-`를 치면 차감이 눌리고, ＋ 추가를 누르면 칸의 빼기표도 지워진다. 좁은 폭에서 멤버 선택 칸이 0폭으로 사라지던 격자를 영역 이름으로 고정(휴대폰·1024~1199는 세 줄)
- @ 표시: 카카오톡은 붙여넣은 글의 @이름을 태그로 바꾸지 않으므로 기본을 끔으로 바꾸고 '표시용'이라고 적음. 예전 저장값(mention)은 물려받지 않음. 태그가 필요하면 채팅창에서 @를 직접 입력하라는 안내를 결과 아래에 둠
- 영수증: 메시지 복사(글)에는 사진이 실리지 않으므로 `영수증 N장 보내기` 버튼 추가 — 휴대폰은 공유 창(navigator.share, 파일), PC는 클립보드에 PNG 한 장(여러 장은 세로로 이어 붙임), 둘 다 안 되면 사진 파일 저장. 메시지 복사 뒤 안내와 영수증 칸 설명도 같은 흐름으로
- 결과 명단: 줄마다 붙던 버튼 둘(송금 앱 열기/계좌·금액 복사 + 금액 복사)을 `복사` 하나로 — 모임장 화면이라 송금은 쓸 일이 없고, 휴대폰에서 버튼이 잘렸다. 복사 내용은 '이름님 금액 · 입금계좌 …' 한 줄(다른 결제자에게 갈 줄에는 계좌를 붙이지 않음)
- 메시지·이미지: 날짜를 `2026년 9월 20일 (일)` 꼴로, 결제자 부담 줄의 조합 이모지(🧑‍🍳)를 단일 이모지로, 결과 머리의 날짜 줄을 제목·총 비용 아래 전체 폭으로
- 검증: uitest.js 33건, nametest.js 7건, settle-test.js 9건, settleview.js, 390/768 가로 넘침 없음

상태 값: 대기 → 진행 → 완료. 검증 도구는 scratchpad 의 playwright 스크립트(로컬 서버 + 테스트 데이터, 실서비스 데이터 미사용).
