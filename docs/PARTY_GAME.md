# 모임 자리 게임 (party.html) 명세

2026-10-18, 97차에 처음 만들고 2026-10-19, 98차에 화면과 연출을 새로 짰다. 모임 자리에서 폰 하나를 돌려 가며 하는 게임 묶음. 혼자 키우는 기존 두 게임과 달리 커뮤니티의 본업(모임)에 붙는다.

## 1. 순간과 조건

- 식사 뒤 20분, 카카오톡 안 브라우저, 한 손, 설치와 로그인 없음.
- 1분 안에 시작하고 5분에서 15분이면 끝난다. 다음 모임에서 또 꺼낸다.
- 입구는 모임 글이다. 오늘이거나 진행 중인 모임 카드의 '이 명단으로 모임 자리 게임' 을 누르면 참석 명단이 그대로 들어온다(party.html?bung=글번호). 게임 목록(games.html)에서도 연다.
- 결과는 서버에 남기지 않는다. 명단과 사람마다 색, 소리 켬끔은 이 기기(localStorage), 진행 중인 판과 게임별 설정과 라이어 전적은 이 탭(sessionStorage)에 남아 새로고침 뒤 이어진다.

## 2. 화면

- 어두운 밤하늘 무대. 로비(쪽 안)와 게임 화면(화면 전체를 덮음) 둘로 나눈다. 게임마다 색이 있다: 뽑기 주황, 밸런스 보라와 분홍, 라이어 파랑과 청록.
- 제목 글꼴은 Black Han Sans(Google Fonts, 못 읽으면 Pretendard 굵게), 본문은 Pretendard.
- 로비: 주사위 모양 로고와 제목, 소리 단추, 플레이어 판(사람마다 색 동그라미와 짧은 이름, 추가 칸), 게임 카드 셋(그림, 한 줄 소개, 인원과 시간). 인원이 모자라면 카드에 'N명 더 필요' 를 달고, 누르면 안내와 함께 플레이어 창이 열린다.
- 게임 화면: 위에 나가기, 게임 그림과 제목, 소리 단추. 가운데 한 화면씩, 아래에 붙는 단추 줄. 밸런스 게임은 위에 문제 진행 막대.
- 그림(로고, 회전판, A 대 B, 가면 카드)은 모두 SVG 로 그 자리에서 그린다. 그림 파일은 공유용 미리보기 그림(assets/og-party.jpg, 1200x630) 하나.

## 3. 명단

- 출처 셋: 모임 글의 참석 명단(site_bung_attend_v, 이미 공개된 것), 직접 적기(멤버 목록 자동완성 member_find), 이 기기의 내 닉네임.
- 같은 이름은 NFC 정규화와 공백, 대소문자를 무시해 한 번만. 40명까지. 로비에는 15명까지 보이고 나머지는 '더 보기'.
- 화면에 보이는 이름은 첫 낱말(채팅방 닉네임은 '이름 동네 성별 출생연도' 꼴이라 길다). 첫 낱말이 겹치면 두 낱말, 그래도 겹치면 전체. 플레이어 창에는 전체 이름.
- 사람마다 색 12가지 가운데 지금 가장 적게 쓰인 색을 넣을 때 정해 이 기기에 남긴다(12명까지는 모두 다른 색).
- 모임 글에서 열면 명단을 넣은 뒤 주소에서 bung 을 뺀다. 새로고침 때 손으로 뺀 사람이 다시 들어오지 않게. 다시 넣기는 로비 모임 줄의 단추.
- 플레이어 창은 아래에서 올라오는 창(뒤로 가기와 끌어 닫기는 site-core). 모두 비우기는 확인 창을 거친다.

## 4. 세 게임

### 뽑기
- 한 명: 12명까지는 회전판, 그보다 많으면 슬롯. 회전판은 손가락으로 밀면 따라 돌고 놓는 빠르기로 돈다(살짝 누르면 단추와 같음). 뽑힐 사람은 돌기 시작할 때 고르게 정하고, 바늘이 그 칸 안에 멈추도록 감속한다. 칸을 지날 때마다 딸깍 소리와 바늘 튕김, 멈추면 뽑힌 칸만 테두리와 나머지 흐림, 이름은 멈춘 자리에서 거꾸로 서지 않게 돌기 시작할 때 맞춘다. 결과 팝업에 미션 카드 주기, 다시 돌리기, 빼고 돌리기(뽑힌 사람을 이번 판에서 빼고 바로 다시), '뺀 사람 다시 넣기'.
- 순서: 세 번 섞는 모습을 보여 주고 1번부터 차례로 불을 켠다. 복사.
- 팀: 4명부터, 2팀에서 6팀(명단의 절반까지). 카드 돌리듯 한 사람씩 팀에 넣는다. 팀 이름은 색(보라, 주황, 초록, 파랑, 분홍, 노랑). 복사.
- 카드: 미션 카드(28장)와 이야기 카드(43장) 더미. 한 장 돌리고 뒤집는다. 받을 사람 뽑기. 같은 카드는 한 바퀴 돌기 전에는 다시 나오지 않는다.

### 밸런스 게임
- 설정: 문제 종류(음식, 술과 카페, 일상, 동네, 모임. 하나는 남겨야 함), 문제 수 5, 10, 15.
- 흐름: 라운드 스플래시, 문제를 함께 읽고(첫 사람 전에는 '다른 문제로'), 폰을 넘기는 화면(큰 동그라미와 이름, 진행 점)에서 '받았어요' 를 누른 사람만 A, B 큰 칸 가운데 하나를 고른다. 고르면 바로 다음 사람의 넘기기 화면으로 넘어가 앞사람의 선택이 가려진다. 넘기기 화면에서 '앞사람 다시 고르기'.
- 공개: 모두 고르면 3, 2, 1 뒤 비율 막대와 양쪽 사람들, '다수' 도장(같으면 '동률'), 다수 쪽 사람마다 +1, 지금 순위 3위까지.
- 끝: 공감왕(공동이면 함께), 시상대(같은 점수는 같은 등수), 전체 순위. 카카오톡 공유, 결과 복사, 처음으로, 한 판 더.

### 라이어 게임
- 설정: 주제(아무거나 또는 음식, 술과 음료, 장소, 일상 물건, 운동과 취미, 동네와 모임), 토론 시간(없음, 2, 3, 5분). 라이어는 1명. 3명부터.
- 카드 확인: 넘기기 화면 뒤 카드와 지문 단추. 누르고 있는 동안만 카드가 뒤집히고(제시어 또는 '당신이 라이어' 와 주제), 손을 떼면 뒤집히며 앞면 글자를 지운다. 제시어는 누르는 동안만 화면에 글자로 있어 화면 읽기나 찾기로 미리 드러나지 않는다. 키보드는 Enter 나 Space 를 누르는 동안. 0.6초 넘게 봐야 '다음' 이 켜진다. 라이어와 시민의 소리와 진동은 같다.
- 토론: 첫 번째로 말할 사람(무작위)과 한 바퀴 순서, 원형 타이머(끝나는 시각으로 세서 다른 앱을 보고 와도, 새로고침 해도 이어짐, 10초 남으면 빨갛게, 0 이면 알람과 진동, 멈춤과 +1분).
- 투표: 다 같이 손가락으로 지목한 뒤 가장 많이 지목된 사람을 고르고 'OO 님으로 결정'. 북소리 뒤 '라이어!' 또는 '시민' 도장. 라이어가 맞으면 마지막 기회(같은 주제의 다른 셋과 4지선다), 맞히면 라이어 역전승. 빗나가면 진짜 라이어와 제시어를 보여 주고 라이어 승.
- 전적: 이 탭 안에서 시민 대 라이어. 다음 판은 새 제시어와 새 라이어. 같은 제시어는 한 바퀴 돌기 전에는 다시 나오지 않는다.

## 5. 연출

- 효과음은 파일 없이 WebAudio 로 그 자리에서 합성한다(누름, 고름, 딸깍, 휙, 카드, 동전, 삐, 팡파르, 북소리, 심벌, 도장, 알람 등). 처음 누를 때 소리 장치를 깨우고(브라우저 약속), 끄면 아무것도 만들지 않는다. 로비와 게임 화면의 소리 단추는 같은 상태.
- 진동(navigator.vibrate): 돌림판 느린 구간, 뽑힘, 고름, 판정, 타이머 끝. 아이폰은 진동이 없어 그냥 넘어간다.
- 색종이(캔버스, 양쪽 아래에서 쏘거나 위에서 내림): 뽑힘, 밸런스 다수와 최종, 라이어 결과.
- 스플래시(빛살과 큰 글자): 라운드, 3 2 1, 토론 시작. 누르면 건너뛴다.
- 움직임 줄이기 설정이면 색종이를 쏘지 않고, 회전과 슬롯과 스플래시를 짧게, 떠오름과 도장과 카드 뒤집기 움직임을 끈다.
- 그라데이션 글자의 빛 번짐은 같은 글자를 겹친 그림자 층으로 낸다(글자 칠에 filter 를 걸면 크롬이 글자 둘레에 네모를 그림).

## 6. 공통 동작

- 게임 화면이 열리면 기록(history)에 칸 하나를 넣는다. 뒤로 가기는 게임 화면만 닫는다. 진행 중인 밸런스와 라이어 판은 먼저 '게임을 그만할까요?' 를 묻고, 묻는 중에 한 번 더 뒤로 가면 나간다. 결과 팝업이 떠 있으면 팝업만 닫는다.
- 화면 꺼짐 막기(Wake Lock): 게임 화면이 떠 있는 동안만. 지원하지 않는 브라우저는 넘어간다.
- 화면 읽기: 게임 화면은 대화상자(aria-modal), 화면이 바뀌면 초점을 제목으로, 결과는 aria-live 로 한 번 읽는다. Tab 은 게임 화면과 확인 창 안에서만 돈다. Esc 는 팝업, 스플래시, 게임 화면 차례로 닫는다. 누르는 칸은 44px 이상.
- 알림은 게임 화면이 떠 있는 동안 위쪽에 띄워 아래 단추를 가리지 않는다.
- 질문 묶음은 data/party-packs.json. 못 읽으면 안에 든 작은 묶음으로 동작한다. 운영자는 파일만 고쳐 늘린다.
- 공유는 카카오톡 공유(KSHARE) 글 카드. 그림은 고정된 미리보기 그림, 글에는 인원과 문제 수, 전적만 넣고 이름은 넣지 않는다. 이름이 든 결과는 사람이 '결과 복사' 를 눌렀을 때만.

## 7. 파일

- party.html: 틀(로비, 플레이어 창, 게임 화면, 확인 창).
- assets/party.css: 화면 모양 전부.
- assets/party-core.js: 명단과 색, 효과음, 진동, 색종이, 게임 화면 틀(뒤로 가기, 확인 창, 스플래시, 팝업), 저장, 공유와 복사.
- assets/party-games.js: 세 게임.
- assets/og-party.jpg: 공유용 미리보기 그림.
- data/party-packs.json: 질문 묶음.

## 8. 내용의 선

- 사람을 지목하거나 개인의 특성(외모, 나이, 연애, 종교, 정치, 돈, 건강)을 묻는 문제는 넣지 않는다. 닉네임에 동네, 성별, 출생 연도가 들어 있기 때문이다.
- 미션은 1분 안에 끝나고 창피하지 않은 것. 술을 시키는 미션은 없다. 하기 싫으면 다음 카드.
- 기록을 서버에 남기지 않으므로 개인정보 처리방침에 새 항목이 생기지 않는다. 공유는 사람이 단추를 눌렀을 때만 카카오톡으로 나간다.

## 9. 두 번째 단계 후보(이번에 하지 않음)

- 같은 자리에서 각자 폰으로 들어오는 방 모드: Supabase Realtime 방송 채널(표 없이 흘러가는 신호)로 밸런스 게임의 동시 선택.
- 봇이 아침에 '오늘의 한 문제' 를 채팅에 올리고 다음 날 집계를 보여 주는 집에서의 한 판. 하루 넘기는 점수 누적은 두지 않는다.
- 결과 카드를 그림으로 만들어 공유(모임 달력 카드처럼 KSHARE.upload). 이름이 그림에 들어가므로 따로 정해야 한다.
