# 모임 자리 게임 (party.html) 명세

2026-10-18, 97차. 모임 자리에서 폰 하나를 돌려 가며 하는 게임 묶음. 혼자 키우는 기존 두 게임과 달리 커뮤니티의 본업(모임)에 붙는다.

## 1. 순간과 조건

- 식사 뒤 20분, 카카오톡 안 브라우저, 한 손, 설치와 로그인 없음.
- 1분 안에 시작하고 5분에서 15분이면 끝난다. 다음 모임에서 또 꺼낸다.
- 입구는 모임 글이다. 오늘이거나 진행 중인 모임 카드의 '이 명단으로 모임 자리 게임' 을 누르면 참석 명단이 그대로 들어온다(party.html?bung=글번호). 게임 목록(games.html)에서도 연다.
- 결과는 서버에 남기지 않는다. 명단만 이 기기(localStorage)에, 진행 중인 판은 이 탭(sessionStorage)에 남아 새로고침 뒤 이어진다.

## 2. 명단

- 출처 셋: 모임 글의 참석 명단(site_bung_attend_v, 이미 공개된 것), 직접 적기(멤버 목록 자동완성 member_find), 이 기기의 내 닉네임.
- 같은 이름은 NFC 정규화와 공백, 대소문자를 무시해 한 번만. 40명까지.
- 화면에 보이는 이름은 첫 낱말(채팅방 닉네임은 '이름 동네 성별 출생연도' 꼴이라 길다). 첫 낱말이 겹치면 두 낱말, 그래도 겹치면 전체. 명단 칩에는 전체 이름.
- 모임 글에서 열어 명단이 들어오면 명단은 한 줄 요약('가온, 하늘, 지우' 와 고치기)으로 접고, 게임 고르기와 무대가 첫 화면에 오도록 내린다.

## 3. 세 게임

### 뽑기
- 한 명 뽑기: 12명까지는 회전판(SVG, 3.4초 감속 회전, 바늘은 12시, 글자는 멈춘 각도에서 거꾸로 서지 않게, 뽑힌 조각만 테두리와 나머지 흐림), 그보다 많으면 이름이 빠르게 바뀌다 멈추는 슬롯. 돌리기를 누르면 회전판이 화면 안에 오도록 움직인다. '이 사람 빼고 돌리기' 는 뽑힌 사람을 이번 판에서 빼고 바로 다시 돌린다. '모두 다시 넣기' 로 되돌린다. 뽑힌 사람에게 미션 카드.
- 순서 정하기: 명단 전체를 섞어 1번부터. 복사해서 채팅방에.
- 팀 나누기: 4명부터, 2팀에서 6팀(명단의 절반까지). A팀부터 알파벳. 복사.
- 카드 뽑기: 미션 카드(가벼운 것 28장)와 이야기 카드(대화 주제 43장). 받을 사람을 따로 뽑을 수 있다. 같은 카드는 한 바퀴 돌기 전에는 다시 나오지 않는다.

### 밸런스 게임
- 설정: 문제 종류(음식, 술과 카페, 일상, 동네, 모임 가운데 고름), 문제 수 5, 10, 15.
- 흐름: 문제를 함께 읽는다. 폰을 돌려 가며 '받았어요' 를 누른 사람만 'OO 님, 혼자 보고 하나만 고르세요' 화면에서 A, B 가운데 하나를 고른다. 고르면 바로 다음 사람의 넘기기 화면으로 넘어가 앞사람의 선택이 가려진다. 첫 사람은 '다른 문제로' 로 바꿀 수 있고, 언제든 그만하기.
- 결과: 나뉜 비율 막대와 양쪽 사람들, 다수 표시. 다수와 같은 쪽을 고른 사람이 1점, 동률이면 점수 없음. 문제마다 현재 3위까지, 끝나면 공감왕과 전체 순위(같은 점수는 같은 등수).
- 끝: 같은 명단으로 한 판 더, 결과 복사, 카카오톡 공유(KSHARE, 글 카드), 처음 화면으로.

### 라이어 게임
- 설정: 주제(아무거나 또는 음식, 술과 음료, 장소, 일상 물건, 운동과 취미, 동네와 모임), 토론 시간(없음, 2, 3, 5분). 라이어는 1명.
- 흐름: 폰을 돌려 가며 '받았어요' 뒤 '길게 눌러 카드 보기'. 누르고 있는 동안만 카드가 뒤집히고(제시어 또는 '당신이 라이어' 와 주제) 손을 떼면 가려진다. 제시어는 누르는 동안만 화면에 글자로 존재해 화면 읽기나 찾기로 미리 드러나지 않는다. 키보드는 Enter 나 Space 로 켜고 끈다. 카드를 한 번 봐야 '다음' 이 켜진다.
- 토론: 첫 번째로 말할 사람을 무작위로 정하고 그 사람부터 한 바퀴 순서. 큰 숫자 타이머(시간 재기, 잠깐 멈춤, +1분). 끝나는 시각으로 세서 카카오톡을 잠깐 보고 와도, 새로고침 해도 그대로 이어진다. 0이 되면 진동.
- 투표: 다 같이 손가락으로 지목한 뒤 가장 많이 지목된 사람을 고르고 'OO 님으로 결정' 을 누른다(잘못 누른 것은 결정 전에 바꾼다). 라이어가 맞으면 라이어에게 제시어 4지선다(같은 주제의 다른 셋이 보기). 맞히면 라이어 역전승, 틀리면 시민 승. 라이어가 아니면 라이어 승.
- 전적: 이 탭 안에서 시민 승과 라이어 승을 센다. 다음 판은 새 제시어와 새 라이어. 같은 제시어는 한 바퀴 돌기 전에는 다시 나오지 않는다.

## 4. 공통 동작

- 진동(navigator.vibrate): 뽑힘, 결과, 타이머 끝. 아이폰은 진동이 없어 그냥 넘어간다.
- 색종이: 밸런스 결과와 라이어 결과에 2초. 움직임 줄이기 설정이면 색종이와 회전, 카드 뒤집기를 모두 끈다.
- 화면 꺼짐 막기(Wake Lock): 밸런스나 라이어 판이 도는 동안만. 지원하지 않는 브라우저는 넘어간다.
- 화면 읽기: 결과는 aria-live 로 한 번 읽는다. 단계가 바뀌면 무대 머리가 보이게 올리고 초점도 무대 머리로 옮긴다. 단추는 44px 이상(명단 칩의 빼기는 36px).
- 아래 단추 줄은 화면 아래에 붙어 한 손으로 누른다(폰은 탭바 위). 알림은 이 쪽에서만 화면 위쪽에 띄워 단추를 가리지 않는다.
- 질문 묶음은 data/party-packs.json. 못 읽으면 안에 든 작은 묶음으로 동작한다. 운영자는 파일만 고쳐 늘린다.

## 5. 내용의 선

- 사람을 지목하거나 개인의 특성(외모, 나이, 연애, 종교, 정치, 돈, 건강)을 묻는 문제는 넣지 않는다. 닉네임에 동네, 성별, 출생 연도가 들어 있기 때문이다.
- 미션은 1분 안에 끝나고 창피하지 않은 것. 술을 시키는 미션은 없다. 하기 싫으면 다음 카드.
- 기록을 서버에 남기지 않으므로 개인정보 처리방침에 새 항목이 생기지 않는다. 공유는 사람이 단추를 눌렀을 때만 카카오톡으로 나간다.

## 6. 두 번째 단계 후보(이번에 하지 않음)

- 같은 자리에서 각자 폰으로 들어오는 방 모드: Supabase Realtime 방송 채널(표 없이 흘러가는 신호)로 밸런스 게임의 동시 선택.
- 봇이 아침에 '오늘의 한 문제' 를 채팅에 올리고 다음 날 집계를 보여 주는 집에서의 한 판. 하루 넘기는 점수 누적은 두지 않는다.
- 결과 카드를 그림으로 만들어 공유(모임 달력 카드처럼 KSHARE.upload).
