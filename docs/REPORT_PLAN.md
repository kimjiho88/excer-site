# 활동 통계 화면 설계 (30차, 2026-09-26)

운영자 요청: 활동 통계의 가독성이 떨어진다. 구성원이 흥미를 갖고 보게 칭호를 올리고, 딱딱한 시각화를 보기 편하고 한눈에 이해되게. 구성, 레이아웃, UX/UI, 디자인을 함께 다시 보고, 고도화된 레퍼런스를 참고해도 좋다.

설계는 워크플로로 만들었다. 현재 화면 비평(참여, 시각화, 레이아웃), 레퍼런스 조사(연말 결산형 서비스, 대화 분석 서비스, 친근한 차트 형식), 실제 데이터 분포 분석을 거쳐 초안 3개(이야기 먼저, 한눈에, 사람 먼저)를 두 심사가 점수 매겼다. 가장 높은 '이야기 먼저'를 바탕으로 다른 초안의 좋은 안을 붙였다.

## 1. 구성

위(A부)는 발행 기간 전체의 이야기이고 기간 칩이 없다. 아래(B부)는 기간을 골라 보는 순위와 요일 시간표다. 섹션마다 붙던 범위 글자와 접기는 없앴다.

| 순서 | 섹션 | 내용 |
|---|---|---|
| 머리 띠 | 기간 이름, 대표 숫자 | 메시지 합계, '하루 평균 N건, N초마다 한 마디', 발행 날짜 |
| A1 | 사람 숫자 3칸 | 이야기한 멤버, 하루 평균 대화(스파크라인), 매일 출석(점 미터, 누르면 이름) |
| A2 | 칭호 | 라벤더 띠. 메달 칭호 6, 시간대 칭호 7, 이야기 칭호 7. 한 사람에 하나 |
| A3 | 내 카드 찾기 | 이름 검색(콤보박스), 유형 점 차트(시간, 관심사, 말 습관) |
| A4 | 흐름 | 결론 제목. 45일 이하는 일별 막대(주말 띠, 평균선, 가장 많은 날), 넘으면 면과 7일 평균선. 같은 x축에 이야기한 멤버 |
| A5 | 하루 | 6시에 시작하는 24시간 막대와 구간 띠 6칸, 요일 하루 평균 가로 막대 |
| A6 | 이야기 | 주제 비중(100% 누적 막대), 많이 나온 말, 분위기 숫자 6칸 |
| A7 | 요약 카드 | 방 카드, 멤버 카드(이미지로 저장) |
| B | 기간별로 보기 | 최근 7일, 최근 30일, 전체, 직접 선택. 숫자 4칸(직전 기간 대비), 순위(메시지, 함께한 날, 늘어난), 요일과 시간(하루 평균, 폰은 3시간 묶음) |
| 시트 | 멤버 카드, 칭호 상세 | 이름이 나오는 곳 어디서 눌러도 같은 카드. 폰은 아래 시트, 넓은 화면은 오른쪽 서랍 |

폰(390)에서는 바로가기 줄을 칭호 다음에 두어 첫 화면에 칭호 첫 줄이 보인다. 1080px 이상에서는 바로가기 줄을 고정한다.

## 2. 데이터 규칙

- **반쪽 날**: 발행을 그날 했거나 마지막 날이 20시 전에 끝나고 평소의 30%도 안 되면 '집계 중'. 합계에는 넣고 평균, 날 단위 계산(개근, 연속, 활동일)에서는 뺀다.
- **봇**: 이름 끝이 bot 이거나 오픈채팅봇인 계정은 목록, 칭호, 유형, 순위, 멤버 수에서 뺀다.
- **하루 구간**: 아침 6~10시, 점심 11~13시, 오후 14~17시, 저녁 18~21시, 밤 22~0시, 새벽 1~5시. 시간 막대, 구간 띠, 시간대 칭호, 유형, 멤버 카드가 함께 쓴다.
- **단어**: 말버릇, 호칭, 봇과 시스템 단어를 화면에서 거른다(이미 발행된 통계에도). 파서도 같은 단어를 불용어에 넣었다(chat-parser.js v9). 홈의 지난달 활동도 같은 목록으로 거른다.
- **공개하지 않는 것**: 입장 수, 나간 수, 활동 지수 36.5, 지니 집중도, 원문.

## 3. 칭호

- 20개, 한 사람에 하나. 칭호마다 상위 3명 후보를 1위 대비 강도로 줄 세워 칭호도 사람도 비어 있을 때 준다. 활약왕은 늘 실제 1위. 같은 점수는 공동(최대 3명).
- 비율 칭호(모임 지킴이, 정보통, 시간대 6개, 주말 지킴이, 맛집 탐험가, 나들이 대장, 질문왕, 사진 기록가, 이모티콘 장인)는 메시지 pubMin(= max(100, 4 x 온전한 날 수))건 이상인 멤버끼리 자기 메시지 가운데의 비중으로 겨루고, 방 비율보다 높아야 자격이 있다(시간대는 1.3배, 주말은 1.5배).
- 1위가 아닌 사람이 받으면 ', 부문 N위'를 붙이고 칭호 상세에 실제 상위 3명을 보인다.
- 함께 받는 기록: 매일 출석(온전한 날 모두), 7일 넘게 이어서. 유형: 메시지 50건 이상이면 모두 시간 유형을 받는다.
- 실제 대화(2026년 9월, 77명): 칭호 20개를 20명이 받음, 부문 상위 3명에 38명, 매일 출석 19명, 7일 연속 49명, 유형 59명. 3개월 자료도 20개, 20명.

| 묶음 | 칭호 |
|---|---|
| 메달(그림) | 활약왕, 성장왕(최근 7일과 그 앞 7일), 폭풍 수다(하루 최다), 모임 지킴이, 환영요정, 정보통 |
| 시간대 | 아침반, 점심반, 오후반, 퇴근반, 밤반, 새벽반, 주말 지킴이 |
| 이야기 | 맛집 탐험가, 나들이 대장, 질문왕, 사진 기록가, 이모티콘 장인, 이야기꾼(글자 수), 첫 마디(조용하던 방에 먼저 말함) |

리액션왕(메시지 수와 거의 같은 순위)과 꾸준함(동점을 한 명에게 주던 것)은 뺐다. 꾸준함은 매일 출석 기록으로 옮겼다.
