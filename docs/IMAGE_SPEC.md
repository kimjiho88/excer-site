# 이미지 규격 (내부 문서)

이미지는 별도로 제작합니다. 사이트는 이미지 없이도 완성된 상태이며, 아래 자리에 파일이 있을 때만 그 자리가 열립니다. 이미지 개수에 맞춰 섹션을 만들지 않습니다. 자리는 홈 대표 그림·공유 미리보기와, 2026-09 에 더한 탭별 머리 배너·머리 스팟·빈 상태 그림·오늘 뭐 먹지·오프라인입니다(4~8절). 기획과 생성 프롬프트는 `docs/IMAGE_PLAN.md`.

공통 규칙(4~8절): 모든 자리는 `<img … onerror>` 로 붙어 파일이 없거나 못 읽으면 자리째 접히고 글·버튼만 남는다(빈 상자·깨진 아이콘 없음). 원본은 `assets/img/src/<이름>.webp`(생성 크기 그대로, 품질 0.92), 웹용은 `assets/img/<이름>-<폭>.webp` 두 단계(1x·2x)를 srcset·sizes 로 고른다. 줄이기는 `scratchpad/mkimg2.js`(크로미움 캔버스, 가운데 자르기 → 두 배씩 줄이기). 장식 그림은 `alt=""`, 장면 그림은 "…그린 일러스트" 대체 텍스트. 인쇄에서는 전부 숨김, 고대비 모드에서는 테두리 한 줄.

색 기준: 페이지 바탕 `#F7F5EF`, 흰 면 `#FFFFFF`, 살짝 눌린 면 `#EDE9EA`, 브랜드 보라 `#4B2A82`, 글자 `#241E2C`, 보라와 짝인 녹슨 주황 `#A9502D`·황토 `#7E5F25`(라벨·차트에만). 그림의 선명한 주황·빨강은 그림 안에만 둡니다.

## 만들지 않는 자리

- 맛집 식당 사진: 사진 첨부 기능이 없어 자리를 만들지 않음. 첨부 기능이 생기면 목록 행 왼쪽 96 × 96 (1:1), 상세 480 × 320 (3:2) 로 정함.
- 소식 글 이미지: 첨부 기능 없음. 사진은 오픈채팅에서 오감.
- 아이콘·일러스트: 기존 선 아이콘(`assets/icons.js`)으로 충분. 위 자리(4~10절) 밖의 장식 그림은 두지 않음(차트·표 옆, 콜아웃 안, 입력 칸·결과 카드, 소식 목록 행).
