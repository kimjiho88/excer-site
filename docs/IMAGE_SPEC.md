# 이미지 규격 (내부 문서)

이미지는 별도로 제작합니다. 사이트는 이미지 없이 완성된 상태가 정식이며, 아래 자리에 파일이 들어오면 그 자리만 열립니다. 이미지 개수에 맞춰 섹션을 만들지 않습니다. 자리는 지금 구조에서 실제로 필요한 세 곳뿐입니다.

색 기준: 페이지 바탕 `#F7F5EF`, 흰 면 `#FFFFFF`, 살짝 눌린 면 `#EEECE4`, 브랜드 `#285244`, 글자 `#242824`.

## 1. 홈 대표 이미지 (선택, 자리 준비됨)

| 항목 | 값 |
|---|---|
| 파일 | `assets/img/home-hero.webp` 또는 `assets/img/home-hero.jpg` (webp 를 먼저 찾음) |
| 켜는 방법 | 파일을 그 경로에 넣으면 끝. 코드 수정 없음. 파일이 없으면 자리도, 빈 상자도 없음 |
| 권장 원본 | 1200 × 900 px, 4:3, 300 KB 이하 (webp 80 품질 권장) |
| PC 표시 (≥ 961px) | 도입 문단 오른쪽, 420 × 315 px, 모서리 10px |
| 태블릿·모바일 (≤ 960px) | 도입 문단·버튼 아래, 화면 폭 전체(390px 화면에서 350 × 262 px), 모서리 10px |
| 잘림 | `object-fit: cover`, 가운데 기준. 4:3 이 아닌 원본은 위아래 또는 좌우가 잘림 |
| 주변 배경 | 페이지 바탕 `#F7F5EF`. 이미지 자체 배경이 흰색이면 경계가 보이므로 사진이나 색이 있는 그림 권장 |
| 내용 | 동네 모임 분위기 한 장. 글자를 넣지 않음(제목·문장은 화면에 있음). 인물 얼굴은 동의 없이 쓰지 않음 |
| 대체 텍스트 | 장식용(`alt=""`). 정보를 담는 이미지가 되면 index.html 의 alt 를 채움 |

## 2. 공유 미리보기 (OG) 이미지 — 지금 파일이 옛 디자인

| 항목 | 값 |
|---|---|
| 파일 | `assets/og.png` (9개 페이지의 `og:image` 가 같은 파일을 가리킴) |
| 규격 | 1200 × 630 px, 1.91:1, PNG 또는 JPG, 500 KB 이하 |
| 표시 | 카카오톡·메신저 링크 미리보기. 카카오톡은 가운데를 기준으로 좌우가 조금 잘릴 수 있으니 글자는 가로 80% 안에 |
| 배경 | 이미지 자체가 배경. 현재 파일은 이전 보라색 디자인에 이전 문구("벙 잡고, 같이 놀고, 끝나면 깔끔하게 정산해요")라 새 톤(`#F7F5EF` 바탕 + `#285244`)과 맞지 않음 |
| 내용 | 서비스명 "동네친구들"과 한 문장. 문구는 홈과 같게: "동네에서 만나고, 함께 기록합니다." |

## 3. 게임 목록 화면 캡처 (선택, 자리 아직 없음)

| 항목 | 값 |
|---|---|
| 파일 | `assets/img/game-zombie.webp`, `assets/img/game-bakery.webp` |
| 권장 원본 | 1280 × 720 px, 16:9 |
| PC 표시 | 각 행 오른쪽, 240 × 135 px (실행 버튼 옆) |
| 모바일 표시 | 제목 아래 화면 폭 전체, 350 × 197 px |
| 잘림 | `object-fit: cover`, 가운데 기준 |
| 주변 배경 | 흰 패널 `#FFFFFF`, 모서리 8px |
| 비고 | 실제 게임 화면 캡처만. 파일이 들어오면 홈과 같은 방식(파일 확인 뒤 자리 열기)으로 games.html 에 붙임 |

## 만들지 않는 자리

- 맛집 식당 사진: 사진 첨부 기능이 없어 자리를 만들지 않음. 첨부 기능이 생기면 목록 행 왼쪽 96 × 96 (1:1), 상세 480 × 320 (3:2) 로 정함.
- 소식 글 이미지: 첨부 기능 없음. 사진은 오픈채팅에서 오감.
- 아이콘·일러스트: 기존 선 아이콘(`assets/icons.js`)으로 충분. 장식 그림은 두지 않음.
