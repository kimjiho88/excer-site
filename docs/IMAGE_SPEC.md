# 이미지 규격 (내부 문서)

이미지는 별도로 제작합니다. 사이트는 이미지 없이도 완성된 상태이며, 아래 자리에 파일이 있을 때만 그 자리가 열립니다. 이미지 개수에 맞춰 섹션을 만들지 않습니다. 자리는 지금 구조에서 실제로 필요한 세 곳뿐입니다.

색 기준: 페이지 바탕 `#F7F5EF`, 흰 면 `#FFFFFF`, 살짝 눌린 면 `#EDE9EA`, 브랜드 보라 `#4B2A82`, 글자 `#241E2C`, 보라와 짝인 녹슨 주황 `#A9502D`·황토 `#7E5F25`(라벨·차트에만). 그림의 선명한 주황·빨강은 그림 안에만 둡니다.

## 만들지 않는 자리

- 맛집 식당 사진: 사진 첨부 기능이 없어 자리를 만들지 않음. 첨부 기능이 생기면 목록 행 왼쪽 96 × 96 (1:1), 상세 480 × 320 (3:2) 로 정함.
- 소식 글 이미지: 첨부 기능 없음. 사진은 오픈채팅에서 오감.
- 아이콘·일러스트: 기존 선 아이콘(`assets/icons.js`)으로 충분. 섹션 장식 그림은 두지 않음.
- 2026-09-27 갱신: 홈 대표 그림 외에도 탭별 머리 배너·스팟·빈 상태 자리를 두기로 함. 자리 목록·규격·생성 프롬프트는 `docs/IMAGE_PLAN.md`. 파일이 들어오면 이 문서의 표에 규격을 옮겨 적는다.
