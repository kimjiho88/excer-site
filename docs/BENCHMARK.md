# 엑서 빵집 타이쿤 — 벤치마킹 (§4)

> 상세 분석 6종 + 요약 분석 7종. 그래픽·UI·캐릭터·이름·에셋은 참고하지 않으며 **성장 구조의 원리만** 추출한다.
> 각 게임의 마지막 두 항목(과금 마찰 / 수치 곡선)은 엑서 빵집에서 "무엇을 제거하고 무엇을 남길지"의 근거다.

## 1. 상세 분석 6종

### 1.1 Animal Restaurant (동물 레스토랑)

| 항목 | 내용 |
|---|---|
| 가게 성장 방식 | 시설(주방·홀·마당·낚시터…) 구역별 해금 + 시설 레벨업. 가게 자체가 콘텐츠의 주인공 |
| 레벨업/진행도 기준 | 코드(재화)로 시설 구매 → 시설이 별점(★)을 올림 → 별점이 구역·손님 해금 게이트 |
| 공간 확장 | 마당 → 낚시터 → 온천 등 **구역 단위 대량 해제**. 잠긴 구역이 실루엣으로 항상 보임 |
| 메뉴/상품 해금 | 레시피 구매(코드 소모). 상위 레시피는 별점 게이트 |
| 장비/시설 업그레이드 | 시설별 다단계 레벨, 효과는 단일(수익↑ 또는 손님 매력도↑) |
| 손님/방문자 해금 | **고객 도감**: 조건(특정 시설·메뉴) 충족 시 희귀 손님 등장, 도감 수집이 핵심 동기 |
| 방치/자동화 | 오프라인 중 자동 판매 + 팁 항아리 누적(상한 있음, 복귀 시 수금) |
| 소셜 | 랭킹/친구 방문은 약함. 사실상 솔로 게임 + SNS 공유 |
| 엑서 빵집에 적용할 점 | 팁 항아리(탭 수금), 손님 도감(멤버 도감으로 변환), 잠긴 슬롯 실루엣 노출, 소프트 실패(손님이 조용히 떠남) |
| 따라 하면 안 되는 점 | 광고 시청이 수익 루프에 깊게 박혀 있음(팁 2배·부스트) — 전부 제거 |
| 평균 세션/복귀 장치 | 5~10분. 팁 항아리 상한 + 시설 완성 타이머가 복귀 유도 |
| 첫 10분 경험 | 주방 청소 → 첫 레시피 → 첫 손님 → 첫 시설 구매까지 논스톱 유도 |
| 과금 유도 마찰(제거 대상) | 광고 게이트, 프리미엄 재화(진주) 전용 시설 |
| 성장 곡선 특성 | 초반 완만·상시 해금, 별점 구간마다 벽. 벽에서 광고/과금 유도 |

### 1.3 Hay Day

| 항목 | 내용 |
|---|---|
| 가게 성장 방식 | 농장(생산 기지)의 설비·밭·동물이 늘며 생산 네트워크가 커짐 |
| 레벨업/진행도 기준 | 판매·주문 경험치 → 레벨 → 작물·설비·기능 해금 |
| 공간 확장 | 토지 확장(도구 아이템 수집) |

| 장비 업그레이드 | **생산 큐 슬롯 확장**(다이아 or 재화), 설비 추가 구매 |
| 손님 해금 | 주문 보드(트럭·배)가 손님 역할 |
| 방치/자동화 | **생산 큐에 걸어두면 오프라인에도 완성** — 엑서 코어 플레이의 원형. 자기 전에 긴 작물을 심는 행동 패턴 |
| 소셜 | 이웃, 조합, 직거래 장터 |
| 적용할 점 | 생산 큐+실시간 타이머, 짧은 메뉴=온라인/긴 메뉴=오프라인 이원화, 다음 해금 상시 노출 |
| 안 되는 점 | 다이아로 타이머 스킵(과금 핵심 — 제거), 토지 확장 아이템 수집 그라인드 |
| 세션/복귀 | 5~15분. **제작 완료 타이머가 복귀 주기를 정확히 만든다**(엑서 2~4h 복귀 목표의 근거) |
| 첫 10분 | 밀 심기(초고속 타이머) → 수확 → 빵 굽기 → 판매까지 체험 — FTUE 5초 단축 타이머의 원형 |
| 과금 마찰(제거) | 다이아 스킵, 큐 슬롯 다이아 해금 |
| 곡선 특성 | 초반 촘촘한 해금(1~2레벨마다), 중반부터 설비 가격 급증 |

## 3. 도출 — "빵집 성장형 타이쿤 공식"

13종 공통 골격에서 추출한 엑서 빵집의 성장 루프:

```
                ┌───────────────────────────────────────────┐
                │              다음 목표 상시 노출              │
                │        ("다음 해금: Lv.N ○○" 헤더 고정)       │
                └──────────────────────┬────────────────────┘
                                       ▼
  [생산 예약]  큐에 메뉴 걸기 ──▶ 실시간 타이머 ──▶ 진열대 재고
      ▲                                              │
      │            (Hay Day: 큐)                      ▼   (Animal Restaurant: 자동판매)
      │                                    손님 자동 방문·구매 + 팁
      │                                              │
      │                                              ▼
      └── 재큐잉 ◀── 의사결정(업그레이드/해금) ◀── 코인·평판·XP
                          │                          │
                          ▼                          ▼
               장비 4종(오븐/진열/계산/간판)      빵집 레벨업
               페이백 즉각(초반 2~4h 감각)           │
                          ▲                          ▼
                          │            5레벨: 외형 변화 / 10레벨: 공간 확장+등급
                          │                          │
                          └──────── 성장의 체감 ◀─────┘
                                (내 빵집이 어제보다 커졌다)
```

**공식의 3원칙** (벤치마킹 결론):
1. **복귀 주기는 타이머와 재고가 만든다** — 에너지·광고가 아니라 (Hay Day/Cat Snack Bar에서 과금 요소를 제거하면 남는 순수 마찰).
2. **성장은 반드시 화면에 보인다** — 슬롯 등장, 외형 교체, 새 손님 (Tiny Tower의 확장 감각 + Animal Restaurant의 실루엣 예고).
3. **손님이 커뮤니티다** — 무개성 스폰(Eatventure)이 아니라 아는 얼굴(멤버)의 대사·단골화 (My Cafe/GPGP의 캐릭터 손님을 실존 멤버로 치환 — 엑서만의 차별점).

### §2 코어 루프 보정 반영 사항

- 세션 루프에 "팁 수금"을 첫 행동으로 고정 (Animal Restaurant의 복귀 첫 손맛).
- 온라인 수요 < 생산 능력으로 설계해 **세션 = 재고를 쌓는 시간, 오프라인 = 재고가 팔리는 시간**으로 역할 분리 (Bakery Story의 진열 판매 + Hay Day의 예약 생산 하이브리드). 시뮬레이터로 검증됨(§GAME_DESIGN 3.4).
- 일일퀘스트는 Cooking Diary의 3축(플레이량/특정 메뉴/성장 행동)을 채택.

### 개인 빵집 vs 공용 빵집 근거 (§8)

13종 전부 **개인 소유 매장이 메인**이고 소셜은 보조(이웃 방문·길드·협동 이벤트)다. 공용 단일 매장을 메인으로 한 메이저 사례는 없음 — 소유감(내 가게)이 리텐션의 원천이기 때문. 게임별: Animal Restaurant(개인+공유 없음), My Cafe(개인+길드 축제), Hay Day(개인 농장+조합), Eatventure(개인), GPGP(개인), Cat Snack Bar(개인), Bakery/Restaurant Story(개인+이웃 방문), Cooking Fever/Diary(개인+길드), CRK(개인 왕국+길드), Tiny Tower(개인), Township(개인+협동조합). → **엑서 확정 구조**: 유저별 메인 빵집 1개 + 멤버는 손님 NPC + 공용 엑서타운은 시즌 이벤트/랭킹용 보조 공간(P2).
