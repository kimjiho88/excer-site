# 카카오 로그인 준비 (운영자 설정)

카카오 로그인 코드를 넣기 전에 운영자가 두 화면(카카오 디벨로퍼스, Supabase)에서 설정하고, 숨은 확인 화면으로 시험합니다. 콘솔 메뉴 이름은 개편에 따라 조금 다를 수 있습니다(2025년 개편 뒤 기준으로 적음).

비밀 값(클라이언트 시크릿)은 Supabase 설정 칸에만 붙여 넣습니다. 채팅, 저장소, 소식 글에는 올리지 않습니다.

## 정한 것 (2026-10-25)

- 사이트의 참석, 취소, 모임 올리기는 카카오 로그인으로 하되, **방에 있는 사람만** 쓸 수 있게 한다. 로그인 뒤 봇이 매일 올리는 멤버 명단(site_members)의 닉네임 하나를 골라 묶고, 명단에 없는 이름은 묶을 수 없다. 명단에서 사라진 닉네임(이름 바꿈, 나감)은 운영 화면에 표시하고 30일 뒤 묶기를 푼다.
- 닉네임을 묶은 뒤에도 **운영진이 확인하고 상세 관리**한다: 운영 화면에 묶기 목록(닉네임, 카카오 회원번호 끝 네 자리, 묶은 날, 명단에 있는지), 풀기, 바꾸기, 바꾼 기록, 같은 닉네임을 둘이 고른 경우 처리, 탈퇴 요청 시 삭제.
- 같은 닉네임은 먼저 묶은 사람으로 두고, 다툼은 운영 화면에서 푼다(승인제 아님).
- 멤버는 명단 드롭다운에서 닉네임을 한 번만 고른다(적는 칸 없음). 묶은 뒤 바꾸기와 풀기는 운영 화면에서만(2026-10-25 저녁 결정. 그 전 판의 '닉네임 바꾸기', '묶기 풀기' 단추는 없앰).
- 로그인 전에 비밀번호로 올린 글과 비밀번호로 적은 참석은 닉네임이 같아도 로그인 계정의 것이 되지 않고 그 비밀번호로 그대로 다룬다(이름만 묶은 다른 사람이 남의 글을 지우거나 자리를 빼앗지 못하게. 2026-10-25 검토 반영). 모임장이 적어 둔 내 이름만 로그인으로 넘겨받는다.
- 공개 뒤 2주는 비밀번호 방식과 함께 쓰고, 그 뒤 참석과 모임 올리기는 로그인만. 댓글과 반응은 지금대로.
- 로그인 단추 옆에 안내 글은 두지 않는다(2026-10-25 저녁 결정. 처리방침은 아래 링크로).
- 사이트가 쓰는 것은 카카오 회원번호와 닉네임(선택 동의) 뿐. Supabase 가 카카오에 늘 세 항목(닉네임, 프로필 사진, 이메일)을 요청하므로 동의 화면에는 셋이 보이고 모두 선택 동의로 둔다. 선택 동의한 이메일과 프로필 사진은 Supabase 계정 정보에만 남고 사이트 표와 화면에는 가져오지 않는다(2026-10-25 확인, 아래 1단계 3).

## 1. 카카오 디벨로퍼스(developers.kakao.com)

지도와 공유에 쓰는 앱 **excer** 에 카카오 로그인을 켭니다. 새 앱은 만들지 않습니다. 컴퓨터 브라우저가 편합니다.

1. 로그인한 뒤 위 메뉴 **내 애플리케이션** 에서 **excer** 를 엽니다.
2. 왼쪽 메뉴 **카카오 로그인** (화면에 따라 카카오 로그인 > 일반): **활성화 설정** 의 상태를 **ON** 으로 둡니다. OpenID Connect 는 켜지 않습니다.
3. 왼쪽 메뉴 **카카오 로그인 > 동의항목**. Supabase 는 카카오에 늘 닉네임, 프로필 사진, 이메일 세 항목을 요청하므로 셋 다 **선택 동의** 로 켜야 합니다(하나라도 '사용 안 함' 이면 로그인할 때 KOE205). 이메일은 비즈 앱에만 열리는 항목이므로 먼저 아래 '비즈 앱 전환' 을 합니다.
   - **비즈 앱 전환**: 왼쪽 메뉴 **앱 > 일반**(화면에 따라 앱 > 비즈니스)의 **비즈 앱 전환** 을 누르고 **개인 개발자 비즈 앱 전환** 을 고릅니다. 사업자 번호 없이 되며, 사용 목적을 고르고 전환을 누르면 바로 끝납니다. 앱 이름과 키는 바뀌지 않습니다.
   - **닉네임**(profile_nickname): 설정을 눌러 **선택 동의**, 동의 목적 칸에 `모임 참석 본인 확인` 을 넣고 저장합니다. 필수 동의는 검수가 필요할 수 있어 선택으로 둡니다.
   - **프로필 사진**(profile_image): **선택 동의**, 동의 목적은 `카카오 로그인 연결에 필요(사이트는 쓰지 않음)` 로 적습니다.
   - **카카오계정(이메일)**(account_email): **선택 동의**, 동의 목적은 같은 문장. **정보 수집 후 제공** 칸은 체크하지 않습니다(체크하면 동의하지 않은 사람에게 카카오가 이메일을 한 번 더 묻습니다).
   - 그 밖의 항목은 켜지 않습니다.
4. 왼쪽 메뉴 **앱 > 플랫폼 키** (개편 전 화면이면 앱 설정 > 앱 키)에서 **REST API 키** 줄을 눌러 상세 설정을 엽니다. 2025년 개편으로 로그인용 리다이렉트 URI 와 클라이언트 시크릿은 이 안에 있습니다(카카오 로그인 메뉴에는 없습니다).
   - **리다이렉트 URI**: 등록을 눌러 `https://drggzlnzwvkhtalvkqyo.supabase.co/auth/v1/callback` 을 넣고 저장합니다. 이 값 하나만 둡니다. 글자가 하나라도 다르면(끝의 슬래시, http) 로그인할 때 KOE006 오류가 납니다.
   - **클라이언트 시크릿**: 코드가 없으면 **코드 생성**, 활성화 상태를 **사용함** 으로 둡니다. 이 코드는 2단계의 Supabase 칸에만 붙여 넣습니다.
   - 같은 화면 위쪽의 **REST API 키** 값도 2단계에서 씁니다(복사 단추).
5. 같은 **플랫폼 키** 화면에서 **JavaScript 키** 상세의 **JavaScript SDK 도메인**(개편 전 이름은 사이트 도메인)에 `https://excer-site.vercel.app` 이 있는지 봅니다. 지도와 공유가 이미 되므로 보통 있습니다. 없으면 더합니다.
6. **앱 > 일반** 에 개인정보 처리방침 URL 칸이 있으면 `https://excer-site.vercel.app/privacy.html` 을 넣습니다. 없으면 넘어갑니다.

## 2. Supabase 대시보드(supabase.com/dashboard)

프로젝트 **drggzlnzwvkhtalvkqyo** 를 엽니다.

1. 왼쪽 **Authentication** 아이콘을 누르고, CONFIGURATION 아래 **Sign In / Providers** 를 엽니다.
2. 위쪽 **User Signups** 의 **Allow new users to sign up** 이 켜져 있는지 봅니다. 꺼져 있으면 처음 로그인하는 사람이 막힙니다.
3. 아래 **Auth Providers** 목록에서 **Kakao** 를 펼칩니다.
   - 이미 **Enabled** 이면 **REST API Key** 칸의 값이 1단계 4의 REST API 키와 같은지 봅니다. 다르면 바꾸지 말고 개발 세션에 '키가 다름' 이라고만 알립니다(바꾸면 미니게임에서 이미 카카오로 로그인한 계정이 이어지지 않습니다).
   - 꺼져 있으면 **Enable Sign in with Kakao** 를 켜고, **REST API Key** 에 REST API 키를, **Client Secret Code** 에 클라이언트 시크릿 코드를 붙여 넣습니다.
   - **Allow users without an email** 을 켭니다. 이메일을 받지 않으므로 이것이 꺼져 있으면 로그인이 막힙니다(예전에 카카오 로그인이 안 된 가장 유력한 원인).
   - 같은 칸의 **Callback URL (for OAuth)** 이 `https://drggzlnzwvkhtalvkqyo.supabase.co/auth/v1/callback` 인지 봅니다(1단계 4에 넣은 값과 같아야 함).
   - **Save**.
4. CONFIGURATION 아래 **URL Configuration** 을 엽니다. **Redirect URLs** 의 **Add URL** 로 `https://excer-site.vercel.app/**` 를 넣고 저장합니다(이미 있으면 그대로). **Site URL** 은 그대로 둡니다.

## 3. 설정 확인(반영 전 시험)

메뉴에 없는 운영진 전용 화면입니다. 사이트의 글, 참석, 운영 자료는 바뀌지 않고, 다른 화면의 로그인과도 섞이지 않습니다.

1. 폰에서 `https://excer-site.vercel.app/kakao-check.html` 을 엽니다(카카오톡 안 브라우저도 됩니다).
2. **카카오 로그인** 을 누르고, 카카오 동의 화면에 닉네임, 프로필 사진, 카카오계정(이메일) 셋이 모두 **선택**(체크를 풀 수 있음)으로 보이는지 봅니다. 세 항목 모두 체크를 풀고 동의해도 로그인이 됩니다.
3. 돌아와서 **로그인 성공. 설정이 맞습니다** 가 나오면 끝입니다. 선택 동의한 항목이 있으면 '사이트는 이 항목을 쓰지 않는다' 는 줄이 같이 나옵니다. 오류가 나오면 화면의 '고칠 곳' 대로 고친 뒤 다시 합니다.
4. 끝나면 **로그아웃** 을 누릅니다. 이 시험으로 Supabase 에 운영자 본인의 로그인 정보가 하나 생기며, 그대로 두어도 됩니다(나중에 운영진 계정으로 씁니다).

막히면

- 카카오 화면에 KOE006: 리다이렉트 URI 글자가 다릅니다(1단계 4).
- 카카오 화면에 KOE101: 앱 키가 다르거나 Supabase 의 REST API Key 가 틀렸습니다(2단계 3).
- 카카오 화면에 KOE205 와 account_email 또는 profile_image: Supabase 가 늘 요청하는 세 항목 가운데 '사용 안 함' 인 것이 있습니다. 비즈 앱으로 바꾸고 1단계 3대로 셋을 선택 동의로 켭니다(2026-10-25 에 이 오류를 이렇게 풀었습니다).
- 카카오 화면에 KOE205 와 profile_nickname: 1단계 3의 닉네임 동의항목이 저장되지 않았습니다.
- 돌아온 화면에 email 이 든 영어 오류: 2단계 3의 Allow users without an email 이 꺼져 있습니다.
- 로그인 뒤 확인 화면이 아니라 홈으로 가면: 2단계 4의 Redirect URLs 에 값이 없습니다.

## 6. 서버 SQL 과 공개 순서(112차 코드가 반영된 뒤, 운영자)

코드는 서버 함수가 있을 때만 단추를 보이므로, SQL 을 돌리기 전에는 사이트가 그대로입니다.

1. 태블릿 Termux 의 run 창에서 Ctrl+C 로 봇을 멈춥니다.
2. [SQL Editor](https://supabase.com/dashboard/project/drggzlnzwvkhtalvkqyo/sql/new) 에서 `sql/backup.sql` 을 Run 하고 Download CSV 로 받아 둡니다.
3. `sql/2026-10-25-kakao-login-1.sql`, `-2.sql`, `-3.sql`, `-4.sql`, `-5.sql` 을 이 차례로 하나씩 붙여 넣고 Run 합니다(네 쪽까지 이미 돌렸으면 5쪽만). 결과는 sql/README.md 의 '카카오 로그인 (2026-10-25)' 절과 같아야 합니다(4번 끝에 `카카오로그인 1`, `함수 15`. 5번 끝에 `명단함수 1`, `스스로풀기 0`).
4. `python excer_bot.py run` 으로 봇을 다시 켭니다(글을 옮기거나 지우는 SQL 이 아니므로 reset 은 하지 않습니다).
5. 운영 화면(ops.html) 데이터 탭의 **카카오 로그인 묶기** 칸을 봅니다. 보이기는 처음에 **운영진 기기만** 입니다. 즉 운영 화면을 한 번 연 기기의 소식 화면에만 카카오 단추가 보입니다. 폰에서 보려면 폰 브라우저로 `https://excer-site.vercel.app/news.html?kakao=1` 을 한 번 엽니다(그 브라우저에만 켜짐).
6. 폰의 소식 화면에서 **카카오 로그인**, 닉네임 고르기(명단 드롭다운에서 본인 이름, 한 번만), 모임 참석과 취소, 모임 올리기와 고치기를 해 봅니다. 운영 화면의 묶기 칸에 본인 줄이 생기고, 바꾸기와 풀기와 기록 보기가 되는지 봅니다. 로그인 전에 비밀번호로 올린 글과 참석은 그대로 비밀번호 창이 뜹니다(로그인으로 넘어오지 않음).
7. 문제가 없으면 소식 공지로 알리고(아래 문안) 운영 화면에서 보이기를 **모두** 로 바꿉니다. 처리방침의 개정은 2026년 10월 25일부터 적용이므로(운영자 결정으로 당김) 그날부터 켤 수 있습니다. 그때부터 모든 멤버의 소식 화면에 단추가 보입니다.
8. 2주 병행(비밀번호 방식과 같이 씀) 뒤 참석과 모임 올리기를 로그인만으로 바꾸는 것은 다음 개발 차례에 합니다. 카카오로 묶인 닉네임은 그 전에도 비밀번호 방식으로 새로 참석하지 못합니다.

공지 문안(소식 공지, 모두로 켜기 7일 전):

```
[안내] 오늘부터 소식 화면의 모임 참석과 모임 올리기에 카카오 로그인을 함께 씁니다.
카카오 로그인 뒤 채팅방 닉네임을 명단에서 한 번 고르면 그 뒤로는 비밀번호 없이 참석과 취소가 됩니다. 닉네임은 한 번만 고를 수 있고, 바꾸려면 운영진에게 알려 주세요.
받는 정보는 카카오 회원번호와 닉네임뿐이며, 자세한 내용은 사이트의 개인정보 처리방침(카카오 로그인 항목)에 있습니다.
비밀번호 방식은 2주 동안(11월 8일까지) 함께 쓸 수 있습니다.
```

- 소식 화면에 단추가 없음: 보이기가 끔이거나, 운영진 기기가 아닌 브라우저입니다(5번). 서버 함수가 없어도 안 보입니다.
- 로그인 뒤 '사이트 닉네임 목록에 없는 이름': 봇이 올린 명단에 그 이름이 없습니다. 운영 화면 데이터 탭의 멤버 닉네임 목록 때를 보고, 봇이 오늘 명단을 올렸는지 봅니다.
- '이미 다른 계정이 묶은 닉네임': 운영 화면 묶기 칸에서 그 줄을 보고 풀거나 바꿉니다.
- '로그인 전에 비밀번호로 적은 참석입니다': 그 참석은 그때 넣은 비밀번호로 취소합니다(화면이 비밀번호 창을 엽니다).
- '카카오 로그인이 지금 꺼져 있습니다': 운영 화면의 보이기가 끔입니다. 끔이면 서버도 막습니다.
