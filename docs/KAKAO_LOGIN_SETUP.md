# 카카오 로그인 준비 (운영자 설정)

카카오 로그인 코드를 넣기 전에 운영자가 두 화면(카카오 디벨로퍼스, Supabase)에서 설정하고, 숨은 확인 화면으로 시험합니다. 콘솔 메뉴 이름은 개편에 따라 조금 다를 수 있습니다(2025년 개편 뒤 기준으로 적음).

비밀 값(클라이언트 시크릿)은 Supabase 설정 칸에만 붙여 넣습니다. 채팅, 저장소, 소식 글에는 올리지 않습니다.

## 정한 것 (2026-10-25)

- 사이트의 참석, 취소, 모임 올리기는 카카오 로그인으로 하되, **방에 있는 사람만** 쓸 수 있게 한다. 로그인 뒤 봇이 매일 올리는 멤버 명단(site_members)의 닉네임 하나를 골라 묶고, 명단에 없는 이름은 묶을 수 없다. 명단에서 사라진 닉네임(이름 바꿈, 나감)은 운영 화면에 표시하고 30일 뒤 묶기를 푼다.
- 닉네임을 묶은 뒤에도 **운영진이 확인하고 상세 관리**한다: 운영 화면에 묶기 목록(닉네임, 카카오 회원번호 끝 네 자리, 묶은 날, 명단에 있는지), 풀기, 바꾸기, 바꾼 기록, 같은 닉네임을 둘이 고른 경우 처리, 탈퇴 요청 시 삭제.
- 같은 닉네임은 먼저 묶은 사람으로 두고, 다툼은 운영 화면에서 푼다(승인제 아님).
- 공개 뒤 2주는 비밀번호 방식과 함께 쓰고, 그 뒤 참석과 모임 올리기는 로그인만. 댓글과 반응은 지금대로.
- 로그인 단추 옆에 '닉네임만 받습니다' 한 줄과 처리방침 링크.
- 카카오에서 받는 것은 카카오 회원번호와 닉네임(선택 동의) 뿐. 이메일과 프로필 사진은 받지 않는다.

## 1. 카카오 디벨로퍼스(developers.kakao.com)

지도와 공유에 쓰는 앱 **excer** 에 카카오 로그인을 켭니다. 새 앱은 만들지 않습니다. 컴퓨터 브라우저가 편합니다.

1. 로그인한 뒤 위 메뉴 **내 애플리케이션** 에서 **excer** 를 엽니다.
2. 왼쪽 메뉴 **카카오 로그인** (화면에 따라 카카오 로그인 > 일반): **활성화 설정** 의 상태를 **ON** 으로 둡니다. OpenID Connect 는 켜지 않습니다.
3. 왼쪽 메뉴 **카카오 로그인 > 동의항목**:
   - **닉네임**(profile_nickname): 설정을 눌러 **선택 동의**, 동의 목적 칸에 `모임 참석 본인 확인` 을 넣고 저장합니다. 필수 동의는 검수가 필요할 수 있어 선택으로 둡니다.
   - **프로필 사진**, **카카오계정(이메일)**: **사용 안 함** 그대로 둡니다. 이메일은 비즈 앱에만 열리는 항목이라 켜지 않습니다.
4. 왼쪽 메뉴 **앱 > 플랫폼 키** (개편 전 화면이면 앱 설정 > 앱 키)에서 **REST API 키** 줄을 눌러 상세 설정을 엽니다. 2025년 개편으로 로그인용 리다이렉트 URI 와 클라이언트 시크릿은 이 안에 있습니다(카카오 로그인 메뉴에는 없습니다).
   - **리다이렉트 URI**: 등록을 눌러 `https://drggzlnzwvkhtalvkqyo.supabase.co/auth/v1/callback` 을 넣고 저장합니다. 이 값 하나만 둡니다. 글자가 하나라도 다르면(끝의 슬래시, http) 로그인할 때 KOE006 오류가 납니다.
   - **클라이언트 시크릿**: 코드가 없으면 **코드 생성**, 활성화 상태를 **사용함** 으로 둡니다. 이 코드는 2단계의 Supabase 칸에만 붙여 넣습니다.
   - 같은 화면 위쪽의 **REST API 키** 값도 2단계에서 씁니다(복사 단추).
5. 같은 **플랫폼 키** 화면에서 **JavaScript 키** 상세의 **JavaScript SDK 도메인**(개편 전 이름은 사이트 도메인)에 `https://excer-site.vercel.app` 이 있는지 봅니다. 지도와 공유가 이미 되므로 보통 있습니다. 없으면 더합니다.
6. **앱 > 일반** 에 개인정보 처리방침 URL 칸이 있으면 `https://excer-site.vercel.app/privacy.html` 을 넣습니다. 없으면 넘어갑니다.

## 2. Supabase 대시보드(supabase.com/dashboard)

프로젝트 **drggzlnzwvkhtalvkqyo** 를 엽니다.

1. 왼쪽 **Authentication** 아이콘을 누르고, CONFIGURATION 아래 **Sign In / Providers** 를 엽니다.
2. 위쪽 **User Signups** 의 **Allow new users to sign up** 이 켜져 있는지 봅니다. 꺼져 있으면 처음 로그인하는 사람이 막힙니다.
3. 아래 **Auth Providers** 목록에서 **Kakao** 를 펼칩니다.
   - 이미 **Enabled** 이면 **REST API Key** 칸의 값이 1단계 4의 REST API 키와 같은지 봅니다. 다르면 바꾸지 말고 개발 세션에 '키가 다름' 이라고만 알립니다(바꾸면 미니게임에서 이미 카카오로 로그인한 계정이 이어지지 않습니다).
   - 꺼져 있으면 **Enable Sign in with Kakao** 를 켜고, **REST API Key** 에 REST API 키를, **Client Secret Code** 에 클라이언트 시크릿 코드를 붙여 넣습니다.
   - **Allow users without an email** 을 켭니다. 이메일을 받지 않으므로 이것이 꺼져 있으면 로그인이 막힙니다(예전에 카카오 로그인이 안 된 가장 유력한 원인).
   - 같은 칸의 **Callback URL (for OAuth)** 이 `https://drggzlnzwvkhtalvkqyo.supabase.co/auth/v1/callback` 인지 봅니다(1단계 4에 넣은 값과 같아야 함).
   - **Save**.
4. CONFIGURATION 아래 **URL Configuration** 을 엽니다. **Redirect URLs** 의 **Add URL** 로 `https://excer-site.vercel.app/**` 를 넣고 저장합니다(이미 있으면 그대로). **Site URL** 은 그대로 둡니다.

## 3. 설정 확인(반영 전 시험)

메뉴에 없는 운영진 전용 화면입니다. 사이트의 글, 참석, 운영 자료는 바뀌지 않고, 다른 화면의 로그인과도 섞이지 않습니다.

1. 폰에서 `https://excer-site.vercel.app/kakao-check.html` 을 엽니다(카카오톡 안 브라우저도 됩니다).
2. **카카오 로그인** 을 누르고, 카카오 동의 화면에 **닉네임** 만 보이는지 봅니다(이메일, 프로필 사진이 보이면 1단계 3을 다시).
3. 돌아와서 **로그인 성공. 설정이 맞습니다** 가 나오면 끝입니다. 오류가 나오면 화면의 '고칠 곳' 대로 고친 뒤 다시 합니다.
4. 끝나면 **로그아웃** 을 누릅니다. 이 시험으로 Supabase 에 운영자 본인의 로그인 정보가 하나 생기며, 그대로 두어도 됩니다(나중에 운영진 계정으로 씁니다).

막히면

- 카카오 화면에 KOE006: 리다이렉트 URI 글자가 다릅니다(1단계 4).
- 카카오 화면에 KOE101: 앱 키가 다르거나 Supabase 의 REST API Key 가 틀렸습니다(2단계 3).
- 카카오 화면에 KOE205 와 카카오계정(이메일): Supabase 가 이메일 범위를 요청했습니다. 확인 화면은 닉네임만 요청하므로 보통 나지 않습니다. 나오면 화면을 캡처해 개발 세션에 보냅니다.
- 카카오 화면에 KOE205 와 닉네임: 1단계 3의 닉네임 동의항목이 저장되지 않았습니다.
- 돌아온 화면에 email 이 든 영어 오류: 2단계 3의 Allow users without an email 이 꺼져 있습니다.
- 로그인 뒤 확인 화면이 아니라 홈으로 가면: 2단계 4의 Redirect URLs 에 값이 없습니다.

## 그다음 순서(개발 세션)

1. 서버: 카카오 계정과 채팅방 닉네임을 하나씩 묶는 표(site_kakao_links)와 기록 표, 함수(me_link, me_unlink, me_info, 로그인 판 참석과 취소와 모임 올리기, 운영진 목록과 풀기와 바꾸기). 참석, 취소, 모임 올리기는 서버가 로그인한 계정으로 닉네임을 정한다(화면이 보낸 닉네임을 믿지 않음). 카카오로 묶인 닉네임은 비밀번호 방식으로 새로 참석하지 못한다.
2. 소식 화면: 카카오 디자인 가이드의 노란 '카카오 로그인' 단추, 처음 한 번 닉네임 고르기(명단 검색), 그 뒤 참석과 취소는 비밀번호 칸 없이, 내가 참석한 글 표시, 로그아웃, 묶기 풀기. 로그인 저장은 소식 전용(미니게임, 확인 화면과 따로).
3. 운영 화면: 묶기 목록, 풀기와 바꾸기, 기록, 같은 닉네임을 둘이 고른 경우, 탈퇴 요청 시 묶기와 로그인 정보 지우기.
4. 처리방침에 카카오 로그인 항목(카카오 회원번호, 카카오 닉네임, 묶은 닉네임과 일시, 로그인 기록, 보유 기간)과 브라우저 저장소의 로그인 상태를 더함.
5. 기능은 먼저 운영진에게만 보이게 켜서 실제 소식 화면의 시험 글로 참석, 취소, 올리기를 해 본다. 문제가 없으면 운영진이 소식 공지로 알리고, 7일 뒤 모두에게 켠다(처리방침의 변경 고지). 2주 병행 뒤 참석과 모임 올리기는 로그인만.
6. 켜진 뒤 폰(카카오톡 안 브라우저)에서 한 번 참석해 본다.

## 지킬 것

- 클라이언트 시크릿과 운영진 비밀번호는 채팅, 저장소, 소식 글에 올리지 않습니다.
- 리다이렉트 URI 는 위의 값 하나만 둡니다.
- 동의항목은 닉네임 하나로 시작합니다. 쓰지 않는 항목은 받지 않습니다.
