# 엑서 빵집 타이쿤 — 개발 티켓 (§14)

> 형식: 목적 / 구현 내용 / 데이터 구조 / 파일 / 완료 조건 / 테스트 / 우선순위 / 의존 / 규모(S·M·L)
> 상태: ✅ 완료 · 🔨 이번 세션 구현 · ⏳ 대기

## 의존성 그래프 (권장 순서)

```
T0 데이터 스키마 ──▶ T1 시뮬레이터(밸런스 확정) ──▶ T2 상태/저장(+T2b 디버그)
                                                      │
                    T3 씬/슬롯 ◀──────────────────────┤
                    T4 생산 큐 ◀──────────────────────┤
                    T5 손님/판매/팁 ◀─ T3, T4
                    T6 레벨/해금/연출 ◀─ T5
                    T7 오프라인 정산 ◀─ T2, T4, T5
                    T8 멤버 손님 ◀─ T5
                    T9 일일퀘스트 ◀─ T5, T6
                    T10 FTUE ◀─ T3~T6
                    T11 폴리싱 ◀─ 전체
```

---

### T0 — 데이터 스키마 + balance.json ✅
- **목적**: 모든 수치의 단일 원본 확립(코드 매직넘버 금지)
- **구현**: data/balance·recipes·equipment·levels·customers·members.json 6종
- **완료 조건**: 엔진·시뮬·클라가 같은 파일 로드, 문서 표와 1:1
- **테스트**: `node sim/sync-levels.js` (가시 변화 검수 포함)
- P0 / 의존 없음 / M

### T1 — 시뮬레이터 + 밸런스 확정 ✅
- **목적**: §2.5 페이싱 목표를 수치로 검증한 뒤에만 밸런스 확정(§3.3 검증 의무)
- **구현**: sim/simulate.js — 하루 3세션 D1~D14, 페이백 추정기, PASS/FAIL 게이트. 튜닝 6회전 끝에 전체 통과(결과는 GDD §3.4)
- **완료 조건**: 9개 체크 전체 PASS → 달성
- **테스트**: `node sim/simulate.js --verbose` (exit 0)
- P0 / T0 / L

### T2 — 상태 관리 + 서버 저장/복구 🔨
- **목적**: 카톡 인앱 유실 대비 이중 저장, 서버 시간 권위
- **구현**: bakery-core `newState/migrate` + bakery.html 저장 계층(로컬 디바운스 + Supabase 익명 로그인·bakery_saves upsert 45s), 서버 now() 오프셋 보정
- **데이터**: `bakery_saves(uid PK→auth.users, state JSONB, ver, updated_at)` + RPC `bakery_now()` — stage2/schema_bakery.sql
- **완료 조건**: 새로고침·재접속 후 상태 유지, Supabase 미설정 시 로컬 폴백으로 정상 동작
- **테스트**: 디버그 모드로 저장→리로드→복원 확인
- P0 / T0 / M

### T2b — 디버그 모드 🔨
- **목적**: 실시간 타이머 게임은 시간 가속 없이 테스트 불가(§10)
- **구현**: `?debug=excer` → 패널: 시간 ×10/×60(가상 시계), +1000코인, 레벨 설정, 리셋, 정산 강제
- **완료 조건**: 가속 상태에서 생산·판매·정산이 일관되게 동작
- P0 / T2 / S

### T3 — 쿼터뷰 씬 + 배치 시스템 🔨 (아이러브커피식 재작성)
- **목적**: 매장이 곧 게임 화면 — 성장·꾸미기가 눈에 보이게
- **구현**: 2:1 타일 그리드+스큐 벽 렌더(roomTable 평수), 고정 설비(씬 탭 조작), 가구 상점·배치 모드(furniture.json → state.layout), 분위기→팁 보너스, grade-N 테마, Lv.10 평수 확장
- **완료 조건**: 레벨 변경 시(디버그) 평수·설비·테마 즉시 갱신, 가구 배치/회수/구매 동작
- P0 / T2 / L

### T4 — 생산 큐 + 타이머 🔨
- **목적**: 코어 루프의 시작(Hay Day식 예약 생산)
- **구현**: 주방 탭 — 설비별 큐 3칸, 남은 시간 프로그레스, 완성 → 진열 자동 이동(공간 없으면 대기 표시). 엔진 `enqueue/advance` 사용
- **완료 조건**: 백그라운드 전환 후 복귀 시 타이머 보정 정확
- P0 / T2 / M

### T5 — 손님 동선 + 판매 + 팁 🔨 (아이러브커피식 재작성)
- **목적**: 손님이 걸어 들어와 줄 서고 앉아서 먹는 살아있는 매장
- **구현**: 액터 상태기계(문 입장→줄서기→주문 말풍선→구매→착석/포장→퇴장), 판매 이벤트 동기화, 좌석 가구 점유, 멤버 닉네임·대사·단골 하트, 팁(카운터 탭 수금), 품절 시 시무룩 퇴장(소프트 실패), 직원(제빵사/캐셔) 연출
- **완료 조건**: 표시 판매량 = 엔진 판매량 일치, 좌석 수만큼만 착석, 팁 상한 작동
- P0 / T3, T4 / L

### T6 — 레벨 + 해금 + 보상 연출 🔨
- **목적**: 레벨업이 플레이의 가장 큰 목표
- **구현**: XP바, 풀스크린 레벨업 연출 + "새로 열린 것" 카드(levels.json unlocks), 헤더 "다음 해금: Lv.N ○○", 등급 표시·Lv.10 등급 상승 연출
- **완료 조건**: Lv.2~10 모든 레벨업에서 가시 변화 연출 발생
- P0 / T5 / M

### T7 — 오프라인 정산 🔨
- **목적**: "자기 전에 걸어두면 아침에 차 있다"
- **구현**: 접속 시 `offlineSettle`(서버 경과초) → 복귀 팝업(부재 시간·판매 요약·코인/XP/팁)
- **완료 조건**: 디버그 가속으로 4h 부재 시나리오 검증, 재고 소진 후 판매 정지 확인
- P0 / T2, T4, T5 / M

### T7b — 정산 서버 검증 강화 ⏳
- **목적**: 클라 정산 결과의 서버측 상한 검증(Supabase RPC/Edge Function)
- P1 / T7 / M

### T8 — 멤버 손님 연동 🔨
- **목적**: 커뮤니티 게임의 차별점
- **구현**: members.json 로드(active 필터), 멤버 스프라이트=아바타 이모지+닉네임, 대사 말풍선, 팁 배율, Lv.9 단골 게이지(방문 5회 승격)
- **완료 조건**: members.json 편집만으로 등장 멤버가 바뀜(active:false 즉시 미등장)
- P0 / T5 / M

### T9 — 일일퀘스트 🔨
- **목적**: 일일 루프 완성
- **구현**: 퀘스트 탭 — 판매 30 / 지정 메뉴 8(해금 메뉴 중 요일 순환) / 업그레이드 1. KST 날짜 기준 리셋, 수령 버튼
- **완료 조건**: 자정(서버 KST) 경과 시 리셋
- P0 / T5, T6 / S

### T10 — FTUE 🔨
- **목적**: 첫 3분 내 첫 판매 + Lv.2 (시뮬 검증치: 0.5분/2.0분)
- **구현**: 이름 짓기 → 오븐 유도(하이라이트) → 모닝롤 5초 베이킹 → 첫 손님(호스트 멤버) 4개 확정 구매+대사 → Lv.2 연출 → 퀘스트 안내
- **완료 조건**: 신규 상태에서 무설명 3분 완주 가능
- P0 / T3~T6 / M

### T11 — 폴리싱 ⏳
- **목적**: 획득 피드백 강화(코인 팝, 사운드 검토), 등급 승급 연출 강화
- P1 / 전체 / M
