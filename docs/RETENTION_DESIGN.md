## 2. 하루 루프 설계 (하루 2~3회 × 5~10분)

```
아침  ── 출석 도장(연속 보너스) → 팁 수금 → 오늘의 메뉴 확인 → 큐 풀 채우기 → 퇴장
점심  ── 팁 수금 → 진열 보충 → 일일퀘스트 중간 수령
저녁  ── 팁 수금 → 퀘스트 마무리 → 올클리어 상자 → 업그레이드 1회 → 큐 채우고 퇴장
```
- 세션 사이 복귀 동기: 큐 완성(30분~수시간) · 팁 항아리 상한(수금 유도) · 오프라인 재고 소진(4~12h)
- "오늘 할 일" 5+1: 판매 30개 / ⭐오늘의 메뉴 8개 / 제작 20개 / 팁 3회 수금 / 업그레이드 1회 → **올클리어 보너스 상자**

## 3. 성장 곡선 — "8주+" 재튜닝 결과

**문제(개편 전)**: XP 필요량이 n^1.85로 폭증하는데 XP/일은 정체 → Lv.20이 D61, Lv.42+ 콘텐츠는 사실상 도달 불가(죽은 콘텐츠).

**해법 3종 세트**:
1. **XP 곡선 2구간화**: `Lv.13 미만 = 30·n^1.85(초반 검증 곡선) / 이후 = 1250·(n/13)^0.78` — 후반 필요량을 경제가 실제로 공급 가능한 수준으로
2. **후반 레시피 XP 밀도 상향**: 타르트 이상 xp ≈ 가격×0.42~0.5 (예: 홀케이크 90→210, 기프트세트 460→1200) — 비싼 빵 하나하나가 "보람"이 되게
3. **큐 슬롯 확장 마일스톤**: Lv.18 / Lv.30에서 설비당 +1칸 — 후반 생산 정체 해소 + 눈에 보이는 성장 이벤트

**시뮬 검증 (하루 3세션 · 70일 · 13개 체크 전체 통과)**:

| 시점 | D1 | D3 | D7 | D14 | D28 (4주) | D56 (8주) | Lv.50 |
|---|---|---|---|---|---|---|---|
| 레벨 | 5 | 8 | 11 | 15 | 24 | 41 | **D67 (9.5주)** |

- 초반 1주는 기존 검증 페이스 그대로(재미 붙이기) → 이후 점점 묵직 → 마지막 레시피(기프트세트 Lv.48)가 8~9주차
- 페이백: 초반 업그레이드 회수 중앙값 4.5h(목표 1~6h) · 전 구매 회수 가능
- 검증 명령: `node sim/simulate.js --days 70`

## 5. 튜닝 노브 (운영하며 조정할 값)

- `balance.json → xpCurve`: A/B(초반), lateStart/lateA/lateB(후반) — 시뮬 필수 통과 후 배포
- `balance.json → attendance`: 보상 테이블·연속 보너스 배수
- `balance.json → dailySpecial`: xpMult / tipChanceAdd
- `balance.json → quests`: 5종 타깃·보상 + allClear
- `recipes.json → mastery`: 별 임계(100/500/2000)·판매가 보너스(5/10/15%)
- `balance.json → queue.slotBonusLevels`: 큐 확장 레벨
