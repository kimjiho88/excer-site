## 2. "판매 가능"까지 남은 3개 병목 — 전부 외부 의존

**시스템·밸런스·UX·연출은 자체 해결 가능 영역이며 상용선에 도달했다.**
남은 병목은 전부 에셋 생산 수단이 필요한 항목:

1. **캐릭터/가구/배경 아트 대량 생산** (최대 병목)
   - 필요량: 손님 6~8종 + 멤버 10종 + 가구 상위 20종 + 벽/바닥 텍스처 2세트 ≈ 40장
   - 경로 A: Google API 키 등록(장당 ~$0.03, 총 1~2천원) → 생성·후처리·적용 전자동
   - 경로 B: 오너가 배치 생성해 채팅 붙여넣기(세션 복구 방식 검증됨) → 내가 일괄 적용
2. **BGM 1곡** — 무료 라이선스 트랙(예: Kevin MacLeod 카페 재즈) 파일 첨부 → 볼륨/루프/토글 연동은 코드 준비됨
3. **Supabase 스키마 적용** — `stage2/schema_bakery.sql` + `schema_bakery_social.sql` 실행 → 클라우드 세이브 + 주간 랭킹 실전 가동

## 3. 출시 시퀀스 제안

| 단계 | 내용 | 소요 |
|---|---|---|
| **소프트 런칭 (지금 가능)** | 현재 빌드로 채팅방 소수 공개 → 조작감·밸런스 실측 피드백 | 즉시 |
| **아트 패스** | 병목 1 해소(경로 A 또는 B) → 화풍 100% 통일 | 에셋 수급 후 1~2세션 |
| **사운드 마감** | BGM 도입 + SFX 밸런싱 | 파일 수급 후 반나절 |
| **정식 오픈** | Supabase 가동(랭킹·클라우드 세이브) + members.json 실명 콘텐츠 + 디버그 핀 교체 | 운영자 액션 후 1세션 |
| **라이브 운영** | 시즌 이벤트(계절 나무·한정 메뉴 연동), 공동 목표 운영 | 상시 |
