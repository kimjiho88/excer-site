운영 대시보드

새로 분석한 결과를 아직 서버에 저장하지 않았습니다. 위의 서버에 저장을 누르면 다른 기기에서도 보입니다.

아직 분석한 대화가 없습니다. 봇이 대화를 내보내 올리면 열 때 바로 반영합니다(봇 탭). 파일 올리기로 직접 올려도 됩니다.

멤버 변화

봇이 방 메뉴에서 멤버를 읽어 올릴 때마다 직전 목록과 견준 들어옴, 나감, 이름 바뀜입니다. 하트나 기호만 바뀌었거나 입장일을 뗀 이름은 같은 사람으로 보고 카카오 로그인 묶기와 끝나지 않은 모임의 참석도 따라갑니다. 이 명단으로 대화 기록과 대조합니다.

지금 명단

    사이트 닉네임 목록

    소식 화면에서 멤버가 자기 닉네임을 찾아 고르는 목록입니다. 봇이 방 메뉴에서 읽어 올립니다. 봇이 멈췄을 때는 사이트에 올리기로 대화 기록의 지금 멤버를 올립니다(서버 저장을 하면 사흘 안의 대화 기록일 때 함께 올라갑니다). 봇 자동 갱신이 돌고 있으면 함께 올리지 않습니다(봇이 방 메뉴에서 읽은 목록을 덮지 않게).

    카카오 로그인 묶기

    소식 화면에서 카카오로 로그인한 사람이 고른 채팅방 닉네임입니다. 사이트 닉네임 목록에 있는 이름만 묶을 수 있고, 목록에서 사라지면 '없음' 으로 보이다가 30일 뒤 풀립니다. 바꾸기와 풀기는 기록에 남습니다.

      봇 원격 조종

      태블릿이 집에 있어도 이 화면에서 봇을 잠시 쉬게 합니다. 봇은 1분 안에 따르고, 쉬는 시간이 끝나거나 다시 켜면 봇 공지를 다시 겁니다.

      공지 멈춤: 운영진이 직접 건 공지를 덮지 않게 공지 걸기만 쉽니다. 새 벙 알림은 그대로 올라갑니다.

      전체 멈춤: 알림과 공지를 모두 쉽니다. 그동안 바뀐 것은 알리지 않습니다.

      봇 대화 내보내기

      태블릿의 봇이 매일 방의 대화 내용을 내보내 태블릿 안에서 이 화면과 같은 분석기로 읽고, 결과(사람별 집계와 채팅 언어 점검)만 서버에 올립니다. 대화 원문은 올라오지 않습니다. 반영하면 파일을 올려 분석한 것과 같이 저장합니다. 켜고 끄기와 시각은 위의 봇 설정에서 합니다(태블릿 Termux 에 nodejs 가 있어야 합니다).

      최근 기록

        처음 설치와 봇이 하는 일

        봇 계정으로 로그인한 태블릿의 카카오톡을, 같은 태블릿의 Termux 에서 도는 파이썬이 조작합니다. 사이트를 20초마다 보고, 오늘 벙을 카드로 적은 글(첫 줄 '오늘의 벙 10/9(금) 3건')을 공지로 겁니다. 오늘 벙에 새 벙, 시간이나 장소 바뀜, 마감, 정원 참, 다시 모집, 취소가 있거나 카드에 보이는 벙의 제목이 바뀌거나 날이 바뀌면 다시 올려 겁니다(사이트가 바뀐 뒤 2분 동안 더 바뀌지 않을 때 한 번에). 새 벙은 처음 올라왔을 때 그 벙 주소와 함께 한 번 공유하고, 바뀐 것은 알림을 따로 올리고, 방 메뉴의 멤버를 읽어 사이트 닉네임 목록을 바꿉니다(봇 열쇠가 있을 때). 켜 두면 매일 새벽 방의 대화 내용을 내보내 태블릿 안에서 분석하고 결과만 올립니다.

        1. 봇 계정을 방의 부방장으로 둡니다. 공지는 방장과 부방장만 겁니다.
        2. 태블릿에 F-Droid 에서 Termux 와 Termux:API 를 깔고, Termux 에서 yes | pkg upgrade 로 기본 부품을 먼저 올린 뒤 pkg install python android-tools termux-api curl nodejs 를 실행합니다(nodejs 는 대화 내보내기 분석용).
        3. 개발자 옵션의 무선 디버깅을 켜고 adb pair 127.0.0.1:포트 로 한 번 짝을 맺습니다.
        4. Termux 에서 스크립트를 받고(curl -LO https://excer-site.vercel.app/tools/excer_bot.py) connect 포트, setup, check, test, run --test 로 시험 방에서 확인한 뒤 run 으로 켭니다. 스크립트 받기

        평소에는 태블릿을 만지지 않습니다. 새 판은 봇이 한 시간마다 보고 스스로 받아 다시 켜고(위의 새 판 받기로 바로), 설정은 위의 봇 설정에서 바꿉니다. 태블릿을 다시 켰으면 무선 디버깅 켜기, connect, run 이 필요합니다.

        벙 일정 주소: excer-site.vercel.app/bung

        대화 파일

        카카오톡 채팅방 메뉴의 대화 내보내기로 받은 .txt 파일입니다. 전체 파일을 올립니다. 여러 파일을 함께 올리면 겹치는 부분은 한 번만 셉니다. 파일은 이 기기 안에서만 읽고, 서버에는 분석 결과와 신호에 걸린 줄의 짧은 발췌만 저장합니다.

        여기에 .txt 파일을 끌어다 놓거나 눌러서 선택

        읽지 못한 줄

        시스템 알림 가운데 뜻을 알지 못한 줄입니다. 대화 내용이 아니라 알림 문구입니다. 비어 있으면 모두 읽은 것입니다.
