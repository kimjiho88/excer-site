활동 통계 발행

운영진 전용 페이지입니다. 카카오톡 대화 내보내기 파일을 이 브라우저 안에서만 분석해 활동 통계를 만듭니다. 대화 원문은 서버로 전송되지 않으며 집계 숫자와 단어 빈도만 발행됩니다.

활동 통계 보기 이용 안내

1대화 파일 올리기

카카오톡 채팅방 → 메뉴 → 대화 내용 내보내기(.txt). 여러 파일을 함께 올릴 수 있습니다. 겹치는 날짜는 자동으로 알려 줍니다.

여기에 .txt 파일을 끌어다 놓거나 눌러서 선택

안드로이드, 아이폰, PC 내보내기 형식을 자동으로 인식합니다. 여러 파일을 한 번에 올릴 수 있으며 기간이 겹치면 중복을 정리합니다.

카카오톡 대화 내용 내보내기 → 텍스트로 나온 파일(또는 '나에게 보내기'로 받은 내용)을 열어 전체 선택(Ctrl/⌘+A) 후 복사해서 아래에 붙여넣어 주세요. 업로드 없이 이 브라우저에서 바로 분석합니다.

파일끼리 날짜가 겹칩니다. 같은 기간을 두 번 내보낸 파일을 함께 올리면 메시지가 이중으로 집계될 수 있습니다.

2집계 기간

기간은 자동으로 감지했습니다. 활동 통계의 기간 선택(오늘/이번 주/이번 달)이 제대로 동작하려면 8주 이상을 권장합니다.

~

3멤버 확인

지금 방에 없는 사람(나갔거나 내보낸 사람)은 통계에서 빼는 것이 좋습니다. 아래에 현재 방 멤버 명단을 붙여넣으면 그 사람들만 남깁니다.

운영봇이나 공지 계정처럼 통계에서 뺄 사람은 아래에서 체크를 해제합니다. 비중(%)은 체크된 멤버 기준으로 계산합니다.

4키워드 다듬기

통계에 보여 주기 어려운 단어(민감한 단어, 장소 등)는 ×로 뺍니다. 색점은 자동으로 나눈 분류입니다.

5닉네임 마스킹

닉네임을 첫 글자만 남기기

이 설정을 켜지 않아도 닉네임 뒷부분(지역, 성별, 출생년도)은 발행되지 않습니다. 공백 앞 첫 토막만 저장됩니다. 예를 들어 "엑서 논현 남 88" 은 "엑서" 로 저장됩니다.

닉네임을 한 단계 더 가리고 싶을 때 켭니다. 켜면 발행되는 데이터 자체가 "첫 글자 + *" 로 저장됩니다. 서버에도 원래 닉네임이 남지 않아 발행 후에는 되돌릴 수 없습니다. 미리보기와 JSON에도 똑같이 적용됩니다.

불러오는 중…
서버 설정이 아직 없습니다. 발행 기능을 쓰려면 Supabase 대시보드 → SQL Editor에서 저장소의 sql/setup_all.sql 전체를 붙여넣고 Run 한 뒤, sql/set_admin_password.sql로 운영진 비밀번호를 한 번 정해 주세요. 자세한 순서는 sql/README.md에 있습니다. 설정 전에도 미리보기와 JSON 내려받기는 쓸 수 있습니다.
데이터 처리 방식
  • 발행본에는 집계 숫자와 키워드만 담깁니다. 대화 문장은 들어가지 않습니다.
  • 원본 .txt 는 업로드 즉시 브라우저 메모리에서만 사용하고 페이지를 떠나면 사라집니다.
  • 발행한 통계는 위 목록에서 언제든 삭제할 수 있습니다.
