카톡 파일 하나로
리포트 발행

내보내기 .txt 를 올리면 이 브라우저 안에서만 분석해요. 발행되는 건 멤버·시간대별 집계 숫자와 키워드뿐이에요.

대시보드 보기 필독 안내

🔒 대화 원문은 서버로 전송되지 않아요 — 파일은 업로드 즉시 브라우저 메모리에서만 쓰고 버려요.

1대화 파일 올리기

카카오톡 채팅방 → 메뉴 → 대화 내용 내보내기(.txt). 여러 파일을 함께 올려도 돼요 — 겹치는 날짜는 자동으로 알려드려요.

여기에 .txt 파일을 끌어다 놓거나 눌러서 선택

Android · iPhone · PC 내보내기 형식을 자동으로 알아봐요
여러 파일도 한 번에 — 기간이 겹치면 중복을 정리해드려요

⚠️ 파일끼리 날짜가 겹쳐요. 같은 기간을 두 번 내보낸 파일을 함께 올리면 메시지가 이중으로 집계될 수 있어요.

2집계 기간

기간은 자동으로 감지했어요. 대시보드의 기간 필터(오늘/이번 주/이번 달)가 잘 동작하려면 8주 이상을 권장해요.

~

3멤버 확인

통계에서 뺄 멤버(운영봇, 공지 계정 등)는 체크를 해제하세요. 바로 다시 집계돼요.

4키워드 다듬기

리포트에 보여주기 애매한 단어는 ×로 빼세요. (민감한 단어·장소 등) 색점은 자동 분류된 카테고리예요.

5닉네임 마스킹

발행 데이터에서 닉네임을 가려요

켜면 발행되는 데이터 자체가 "첫 글자 + *" 로 저장돼요. 서버에도 원래 닉네임이 남지 않아서 발행 후에는 되돌릴 수 없어요. (미리보기·JSON에도 똑같이 적용돼요)

✓확인 후 발행

기간 내 메시지-
활동 멤버-
하루 평균-
새 멤버-

미리보기는 이 브라우저에만 저장돼요. 발행하면 같은 제목의 리포트는 새 내용으로 교체돼요. 비밀번호는 저장하지 않아요.

발행된 리포트

불러오는 중…
서버 설정이 아직이에요. 발행 기능을 쓰려면 Supabase 대시보드 → SQL Editor에서 저장소의 sql/site_features.sql 전체를 붙여넣고 CHANGE_ME를 운영진 비밀번호로 바꿔 Run 하세요. 자세한 순서는 sql/README.md에 있어요. 설정 전에도 미리보기·JSON 내려받기는 그대로 쓸 수 있어요.
🔒 데이터는 이렇게 다뤄요
  • 발행본에는 집계 숫자와 키워드만 담겨요 — 대화 문장은 없어요.
  • 원본 .txt 는 업로드 즉시 브라우저 메모리에서만 사용하고 페이지를 떠나면 사라져요.
  • 발행한 리포트는 위 목록에서 언제든 삭제할 수 있어요.
