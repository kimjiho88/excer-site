# 커뮤니티 기능 서버 설정 (5분 소요)

리포트 발행·소식 게시판·정산 공유(입금 체크 동기화)는 Supabase 테이블이 필요합니다.
아래 한 번만 해두면 이후에는 사이트에서 모든 것이 처리됩니다.

## 가장 쉬운 방법 (권장) — 한 번에 설치

`sql/setup_all.sql` **하나만** 실행하면 게시판·대시보드 발행·정산 공유·방문자 카운터가
전부 켜집니다. (아래의 v1/v2/v3 를 순서대로 돌리는 것과 결과가 같고, 순서 실수·재실행 충돌이 없습니다.)

1. [SQL Editor](https://supabase.com/dashboard/project/drggzlnzwvkhtalvkqyo/sql/new) 열기
2. `sql/setup_all.sql` 전체 붙여넣고 **Run**
3. `sql/set_admin_password.sql` 을 열어 비밀번호만 바꾸고 **Run** → 끝

> 이미 일부만 실행해서 에러(예: `42P16 cannot drop columns from view`)가 났더라도,
> `setup_all.sql` 을 그대로 다시 실행하면 깨끗하게 정리되며 완료됩니다.
> **다시 실행해도 운영진 비밀번호는 덮어쓰지 않습니다.**

> ⚠️ 비밀번호를 정하기 전까지는 발행·공지 작성·글 강제삭제가 모두 막혀 있습니다.
> 2번만 하고 3번을 빠뜨리면 리포트를 발행할 수 없습니다.

---

## (수동) 파일별 적용 순서

1. [Supabase 대시보드](https://supabase.com/dashboard) → 기존 프로젝트(`drggzlnzwvkhtalvkqyo`) → **SQL Editor**
2. `sql/site_features.sql` 파일을 열어 전체 복사 → 붙여넣고 **Run**
3. `sql/set_admin_password.sql` 을 열어 비밀번호만 바꾸고 **Run** — 끝!
   - 이 비밀번호는 **공지 작성/고정, 리포트 발행, 글 강제 삭제**에 사용됩니다
   - 운영진끼리만 공유하세요 (8자 이상 권장)
   - 정하기 전까지는 발행·공지·강제삭제가 막혀 있습니다

## 적용 전에도 사이트는 동작합니다

| 기능 | 서버 설정 전 | 서버 설정 후 |
|---|---|---|
| 운영 대시보드 | 예시 데이터 표시 | 발행한 실제 리포트 표시 |
| 소식 게시판 | 준비 중 안내 | 글/댓글 작성 가능 |
| 정산 공유 링크 | 만들 수 없음 — '전체 복사'로 정산 내용 전달 | 입금 체크가 모두에게 실시간 공유 |

## v2 마이그레이션 (게시판 카테고리 개편 + 리액션)

`site_features.sql` 적용 후, `sql/site_features_v2.sql` 도 같은 방법으로 붙여넣고 Run 하세요.
게시판 카테고리(공지/벙 소식/후기/정보/자유)와 게시글 리액션(👍❤️😂👏🔥)이 활성화됩니다.
(v2 도 재실행 안전)

## v3 마이그레이션 (방문자 트래킹)

v2 적용 후 `sql/site_features_v3.sql` 도 같은 방법으로 Run 하세요.
사이트 우측 상단에 "오늘 방문 · 누적 접속" 카운터가 표시됩니다.
(기기별 무작위 키로 하루 1회 집계 — 개인 식별 정보는 저장하지 않습니다)

## 비밀번호 변경

`sql/set_admin_password.sql` 을 열어 새 비밀번호를 넣고 Run 하면 됩니다.
설치 파일(`setup_all.sql` · `site_features.sql`)은 비밀번호를 건드리지 않으므로,
구조를 다시 깔아도 비밀번호는 그대로 남습니다.

**운영진이 바뀌면 반드시 실행하세요** — 이전 운영진의 접근을 끊는 유일한 방법입니다.

## 개인정보 관련

- 리포트 발행 시 **카톡 대화 원문은 서버에 올라가지 않습니다.**
  브라우저 안에서 분석하고, 집계 숫자(멤버별 메시지 수·시간대 분포 등)만 저장됩니다.
- 게시판 비밀번호와 운영진 비밀번호는 해시로만 저장됩니다.
